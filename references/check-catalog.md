# 检查规则总表

本文是审查规则的唯一编号表。下半部分表格由 [`scripts/catalog.py`](../scripts/catalog.py) 生成；
改规则只改 `catalog.py`，再运行 `python3 scripts/catalog.py --write-doc references/check-catalog.md`，
测试会拒绝两者不一致。规则目的与适用边界先对照 [审查纲要](review-charter.md)。

## 编号怎么读

- 规则编号为 `内容域-方式序号`。例如 `PWR-E01`：`PWR` 是电源，`E` 是证据计算，`01` 是该组序号。
  内容域回答“查什么”，方式回答“怎么查”。在用编号不改；新规则接在所在组最大序号之后，组内序号可能有空缺。
- 计划项 ID 为 `规则编号[.实例键].锚点`，例如 `RST-T02.U3.SYS-RST-N`。审查者补查的项同样以规则编号开头，
  如 `PWR-T05.Q7-REVERSE`。每个计划项带 `rule`、`method`、`domain`，合并计划和校验结果时逐项核对。
- 计划、意图的 `schema_version` 为 3，证据为 2；不符合当前总表的文件须重新生成。

## 审查流程

流程按检查方式排列；同一内容域的规则分散在不同阶段执行，靠编号前缀汇总。

| 阶段 | 做什么 | 方式 | 主要产物 |
|---|---|---|---|
| 0 输入准备 | 输入版本与哈希、需求、工况、装配配置，写入 intent | — | `input-manifest.json`、`intent.json` |
| 1 解析 | 解析网表并自检完整性 | — | `db.json` |
| 2 冷跑 | 自动扫描全部内容域，生成计划 | A | `lint-cold.json`、`review-plan-cold.json` |
| 3 资料取证 | 器件身份、官方脚表、资料审计，整理结构化证据 | D（DEV 域先做） | `datasheet-audit.json`、`evidence.json` |
| 4 热跑 | 再次自动扫描并执行证据计算，合并最终计划 | A、E | `lint-hot.json`、`review-plan.json` |
| 5 专家审查 | 按内容域逐项追踪、计算、核对条款 | T、C、D | `review-results.json` 各项 |
| 6 图面目检 | 每页留目检记录 | V | 页面记录 |
| 7 覆盖审计与报告 | 覆盖维度、功能包汇总与未检出确认、结果校验、报告 | Q | `review-gate.json`、报告 |
| 8 改版复验 | 新旧比对、历史意见闭环（仅复审） | H | `diff.json`、改版影响清单 |

专家审查建议按 PWR → RST → CLK → SIG → ANA → PRO → DRV 推进；DOC、DEV、NET、REQ 的
非自动项在对应阶段穿插完成。

## 方式要点

- **A 自动扫描**：只报疑点（FINDING）、候选（CANDIDATE）和提示（INFO），不是结论；零命中不等于通过。
  见 [自动检查](automation.md)。
- **E 证据计算**：只使用带出处的保证值，缺任一项即 INSUFFICIENT；PASS 写明未判定的部分。
  见 [器件资料与证据计算](datasheets.md)。
- **T 连接追踪**：逐跳记录物理脚→网络→已贴器件→网络→物理脚，同时核返回路径与参考地；
  按装配状态和工况分别追。连通只证明导电路径。
- **C 工程计算**：先确认模型，再代入实际拓扑、公差、输入/温度/负载角点；公式见 [WCA 公式](wca-formulas.md)。
  改参数时连带复算相关规则。
- **D 条款核对**：逐条对照准确型号的官方条款、errata、平台规范与需求，保留“文档章节→规则编号”阅读记录；
  平台条款实例化时记录文档/版本/页码、适用器件与模式、预期连接或窗口、实际位号/物理脚/网络与结果。
- **V 图面目检**：极性、pin1/视图、选项表、同名端、NC 标记以图形为证据；新页和变更区细读。
- **Q 覆盖审计**：功能包汇总项（REQ-Q07）不能代替逐电路、逐状态的成员检查；未检出也未声明的功能包由 REQ-Q08 逐个确认。
- **H 版本比对**：旧结论不迁移，见 [改版复审](revision-review.md)。

“来源”列说明计划项由谁产生，“粒度”列说明逐什么对象展开：`Lint 内置`、`检查器·…`、`改版比对` 由脚本执行或生成；
`计划逐对象生成` 按粒度逐对象展开；`功能包成员` 随所属功能包展开；`全板通用` 每块板一项。
各内容域的移交事项只形成下游约束，边界见 [结论与准出](verdicts-and-release.md#4-handoff-与集成约束)。

## 审查纲要与规则归属

目的与取舍见 [审查纲要](review-charter.md)。每条在用规则有一个主纲要，跨域约束仍按判据与 HANDOFF 处理。
这是维护映射，不增加项目检查或填写字段；映射齐全不等于实际审查正确。

| 纲要 | 要回答的问题 | 主归属规则数 |
|---|---|---|
| G1 需求与功能符合 | 要求的功能、接口和性能是否落实到电路？ | 4 |
| G2 器件与连接正确 | 实际器件、物理脚、装配与端到端连接是否正确？ | 32 |
| G3 工况下的功能与性能 | 启动、运行、掉电等适用状态下，电源、控制与信号能否按要求工作？ | 49 |
| G4 参数裕量与器件应力 | 保证值、公差及工作范围是否满足指标和器件能力？ | 22 |
| G5 保护与异常响应 | 需求内的故障、防护及隔离是否有效，动作与恢复是否合理？ | 21 |
| G6 实施、测试与下游约束 | 原理图是否可落实和验证，必要布局、热及测试约束是否明确移交？ | 4 |
| G7 证据覆盖、改进建议与复验闭环 | 是否查全且结论有据，不通过项是否明确如何改进、如何复验？ | 15 |

## 每项为什么查、漏查风险与证据衔接

下面说明检查的合理性，不表示本设计已存在这些问题，也不预设 P0–P3。
衔接指可复用的证据及职责；不是要求所有相关规则都适用，也不是自动生成项目依赖。
实际审查按对象、工况和需求改写说明，并在理由/证据中引用所用检查实例和具体结论。

### DOC 图纸与数据

| 编号 | 在检查什么 | 不查可能漏掉什么 | 与其他检查怎样衔接 |
|---|---|---|---|
| DOC-A01 | 确认网表完整来自本轮成功导出。 | 可能在残缺或旧连接上审查，漏掉整段电路。 | 先于连接和计算检查；导出范围由 DOC-Q01 对账。 |
| DOC-A02 | 核实标为不连接的脚是否被导出器意外连上。 | 无意连接可能造成冲突，或让审查误以为悬空已解决。 | 与 NET-A04 核实际网络，再由 DEV-D05 核该脚允许的处置。 |
| DOC-A03 | 发现会影响物料识别和版本比较的字段空白。 | 同一物料可能被误认成不同物料，造成选料或比对错误。 | 供 DEV-D01 核身份、DOC-Q01 核输入一致性；不直接证明电气失效。 |

| DOC-T01 | 逐种贴装配置核实跳线和可选器件的组合。 | 互斥件同时贴或必要件漏贴可能改变供电及信号路径。 | 各配置分别交给 PWR-T01、SIG-T04 和 RST-T03，不能共用另一配置的通过结论。 |
| DOC-D01 | 核实阻容等值字段的数值和单位是否写错。 | 错误数量级可能被采购或计算沿用。 | 先与 DEV-D01 核实际物料，再交 DEV-C01 等计算真实影响。 |

| DEV-C02 | 核实电容在电压、温度和寿命条件下仍有足够有效容量。 | 标称容量够用而实际容量或寿命不足，可能造成掉压、失稳或提前失效。 | 供 PWR-C09、PWR-C13 和相关时序计算使用；实际温升移交下游。 |
| DEV-C03 | 核实精度器件的公差、温漂和等级是否匹配误差预算。 | 标称值正确仍可能导致输出或测量误差超标。 | 误差目标来自需求，参数交 PWR-E01、ANA-C01 等计算。 |
| DEV-C04 | 核实连接器触点和允许并联方式能承受实际电流。 | 接触点可能过热、压降过大或损坏。 | 电流来自 PWR-C01 和接口能力；实际铜皮与接触温升移交验证。 |
| DEV-C05 | 逐项核实器件在本机工况下能正常工作的前提。 | 供电、输入或配置不满足推荐条件时，核心功能可能不成立。 | 复用 DEV-D01 身份及 PWR-T01 电源路径，补 DEV-E02 未覆盖的条件。 |
| DEV-D01 | 确认实际料号、变体和封装对应所用手册。 | 可能拿另一型号的脚表、门限或额定来证明本器件。 | 为 DEV-D02、DEV-C05 及全部器件计算提供身份前提。 |
| DEV-D02 | 核对原理图中的每个物理脚是否与原厂定义一致。 | 漏脚、错脚或电源脚映射错误可能被后续计算掩盖。 | 先完成 DEV-D01，再交 DEV-D05 核处置、连接检查核真实路径。 |
| DEV-D03 | 确认连接器本端和对端对每个触点的定义相容。 | 电源、地或通信方向可能在连接后相冲突。 | 复用 DEV-E01 的映射，交 SIG-T04 核端到端方向、PRO-D03 核防护。 |
| DEV-D04 | 核实符号、物料字段及资料链接是否准确且相互一致。 | 错误库或物料身份可能流入采购、装配和电气计算。 | 与 DEV-D01/D02 对账；身份冲突下的电气后果须另按分支判断。 |
| DEV-D05 | 逐脚核实连接、上拉、接地或悬空方式是否适用。 | 保留脚或多功能脚处置不当可能导致误模式、漏电或失效。 | 复用 DEV-D02 脚表和当前模式；专用接口、启动检查再核组合行为。 |
| DEV-Q01 | 确认所有适用器件的资料及关键参数都有可定位来源。 | 关键器件可能在没有适用依据的情况下被默认通过。 | 核 DEV-D01 和各计算引用的覆盖，不重复替代其电气判断。 |

### PWR 电源

| PWR-A01 | 发现电源轨可能没有实际供能源。 | 负载可能无电，或仅被信号脚反向供电。 | 候选由 PWR-T01 逐跳追到真实供入。 |

| PWR-A04 | 识别名称相似的多条电源轨是否被意外分开。 | 供电可能断开，或审查把不同电压域当成同一轨。 | 由 PWR-T01、PWR-T06 核供电与返回关系。 |
| PWR-A05 | 发现输入 LC 滤波可能缺少有效阻尼的候选。 | 滤波器与变换器相互作用可能引起振荡或启动异常。 | 阻尼可来自器件和负载；由 PWR-E03/C11 判定，不强制新增电阻。 |

| PWR-E01 | 计算分压设定在公差下的实际电压窗口。 | 标称输出正确而极限电压可能超出负载允许范围。 | 参数来自 DEV-C03，窗口供 DEV-E02 和 PWR-C02 使用。 |
| PWR-E02 | 计算线性稳压器最差输入是否仍保有必要压差。 | 输入降低时输出可能掉压，导致负载失去正常工作保证。 | 复用 PWR-T01 供入范围，结果交 DEV-C05 和 RST-T03。 |
| PWR-E03 | 计算输入滤波器与变换器之间的阻抗及阻尼关系。 | 谐振可能使原本独立稳定的电源出现振荡。 | 复用 PWR-C11 元件参数，与 PWR-C04 核整个电源稳定性。 |
| PWR-T01 | 逐轨追清电源从哪里来、经过什么器件、供给哪些负载。 | 漏供、错供或反向供电可能被局部电压计算漏掉。 | 为 PWR-C01/C02 和 RST-T03 提供源、负载和状态。 |
| PWR-T03 | 逐电源脚核实旁路电容及其实际返回路径。 | 电容虽在图上存在，却可能未给目标电源脚提供旁路。 | 按 DEV-D02 脚表枚举，容量和接法分别交 PWR-C09、PWR-D02。 |
| PWR-T04 | 逐电源域核实必需的电压检测及故障传递路径。 | 监测信号可能漏域或无法触发所需关断/复位。 | 复用 PWR-T01 电源树，门限由 PWR-C06 核、后续动作由 RST-T02/T03 核。 |
| PWR-T05 | 追踪防反接或理想二极管在正反供电时的通路。 | 反接或掉电时可能有未预期的反流和负载带电。 | 先核器件方向与状态，损耗/反流交 PWR-C05、应力交 DEV-C01。 |
| PWR-T06 | 核实各参考地的连接、隔离和回流关系。 | 电源无回路、检测参考错误或隔离被跨接可能漏检。 | 为电平和保护计算提供参考域，隔离跨接另由 PRO-D02 核。 |
| PWR-C01 | 核实电源可提供的功率覆盖同时工作的负载。 | 系统可能在负载组合下掉压、限流或无法达到额定输出。 | 源和负载来自 PWR-T01，电流与损耗交 PWR-C03/C05。 |
| PWR-C02 | 核实变换器在输入、负载范围内能得到要求的输出。 | 设定值正确但占空比、压差或拓扑能力可能不够。 | 复用 PWR-T01、PWR-E01/E02，所得工况供应力和稳定性检查。 |
| PWR-C03 | 核实功率路径中的峰值、平均及有效值电流。 | 磁件饱和、限流误触发或器件电流超额可能漏检。 | 工况来自 PWR-C01/C02，结果供 DEV-C01、DRV-C01/C02 复用。 |
| PWR-C04 | 核实电源控制、补偿及状态转换的动态条件。 | 输出可能振荡、过冲或不能按要求启动和调节。 | 复用 PWR-C02 工作点及 PWR-E03 滤波结论，具体波形验证移交下游。 |
| PWR-C05 | 计算转换损耗并追踪反向供电及放电能量。 | 功耗预算可能不足，或掉电时出现损坏性的反流。 | 复用 PWR-T01/T05 与 PWR-C03，输出散热和保护所需能量边界。 |
| PWR-C06 | 核实限流、欠压、过压等门限与正常工作窗口相容。 | 正常工作可能误停机，故障时又可能保护过晚。 | 工况来自 PWR-C01/C02，保护动作与耐受协同交 PRO-C01。 |
| PWR-C09 | 核实旁路与储能电容能支撑目标负载的电流变化。 | 电压跌落或纹波可能使负载误动作。 | 复用 PWR-T03 路径与 DEV-C02 有效容量，结果供 PWR-C14。 |
| PWR-C10 | 核实去耦电容的耐压、纹波电流及温度条件。 | 电容可能因电气应力失效，即使标称容量足够。 | 复用 PWR-T03 脚组和电源窗口，与 DEV-C01 共用同一器件额定证据。 |
| PWR-C11 | 核实输入滤波器的电流、压降、容量与阻尼参数。 | 滤波元件可能过热、饱和，或引入不稳定。 | 供 PWR-E03 的阻抗计算和 PWR-C05 的损耗预算使用。 |
| PWR-C13 | 计算接通电源时给输入电容充电的浪涌。 | 连接器、开关或电源可能过流，或启动失败。 | 复用 DEV-C02 容量、PWR-T01 路径，功率管耐受交 DRV-C02。 |
| PWR-C14 | 核实电源噪声和纹波是否满足实际负载要求。 | 敏感负载可能误码、精度下降或功能异常。 | 先追 PWR-T01 的真实负载，复用 PWR-C04/C09；无适用噪声要求不强造指标。 |
| PWR-D01 | 确认每组实际供电脚都已进入去耦审查清单。 | 某个电源域可能完全漏查。 | 与 DEV-D02 脚表对账，具体连接、容量和额定由 PWR-T03/C09/C10 核。 |
| PWR-D02 | 核对本器件要求的去耦类型、连接及专用电容条款。 | 普通旁路接法可能被误用于飞跨、补偿或专用稳压电容。 | 复用 PWR-T03 实际连接及准确器件资料，容量资格交 PWR-C09。 |
| PWR-D03 | 核实软启动及输出已有电压时的启动行为。 | 启动可能反向放电、过冲或卡住，影响负载和恢复。 | 复用 PWR-T01 状态、PWR-C05 反流，与 RST-T03 汇合。 |

|---|---|---|---|
| RST-A01 | 发现使能脚偏置可能不符合预期默认状态的候选。 | 上电或驱动高阻时电源可能意外开启或关闭。 | 由 RST-T01 核实际源，再由 RST-E01/C01 核电平。 |
| RST-A02 | 发现使能与供电同时建立而可能缺少有效等待的情况。 | 电源未稳定时负载可能提前运行。 | 由 RST-T03 核顺序要求，RST-C01/C02 核实际窗口。 |

| RST-A04 | 发现使能信号来源不明的候选。 | 审查可能把未驱动或循环依赖的信号当作有效许可。 | 交 RST-T01 逐跳追踪，并与 PWR-T01 检查供电依赖。 |

| RST-A06 | 发现复位或看门狗输出未到达目标复位脚。 | 检测到故障后系统可能仍继续运行。 | 由 RST-T02 追踪实际链路，再交 RST-C02 核动作时序。 |

| RST-E03 | 计算复位信号的有效持续时间。 | 过短脉冲可能无法完成复位，过长则可能妨碍启动。 | 复用 RST-T02 路径，与 RST-C02 核完整复位窗口。 |
| RST-T01 | 追清使能信号的产生、返回和供电条件。 | 电源启动可能依赖尚未建立的自身或其他电源。 | 与 PWR-T01 建立启动关系，电平和时序交 RST-E01/T03。 |
| RST-T02 | 追踪故障检测、看门狗和复位信号是否真正到达目标。 | 有检测器但执行链断开，故障可能无法恢复。 | 复用 PWR-T04 检测范围，电平和脉宽由 RST-E03/C02 核。 |
| RST-T03 | 核实上电、掉电、故障和恢复各状态的顺序。 | 系统可能启动死锁、未授权带电或恢复到错误状态。 | 汇集 PWR-T01、RST-T01/T02 和保护动作的已核结论。 |
| RST-T04 | 核实复位与未初始化期间 IO 的默认状态。 | 外设、功率开关或启动配置可能被意外驱动。 | 默认态供 RST-E02/C01 和 SIG-C08 使用。 |
| RST-C01 | 计算状态采样时输入电平是否已可靠建立。 | 静态电平正确，但采样瞬间可能读到错误配置或许可。 | 复用 RST-T03/T04 顺序和默认态，与 RST-E02 区分电平与时间。 |
| RST-C02 | 计算电源、时钟、复位释放之间的时间关系。 | 复位释放过早或重置不足可能造成随机启动失败。 | 复用 RST-T02/T03 和 CLK-C01/D01，不能只核单个 RC。 |
| RST-D01 | 确认必要的恢复、下载或救援通道可进入。 | 配置或固件损坏后设备可能无法按要求恢复。 | 复用 SIG-D06 的接口与 RST-E02 的启动配置，按需求决定适用性。 |

| SIG-C01 | 计算 I²C 上拉的低电平灌电流与高电平上升时间。 | 上拉太强可能拉不低，太弱则可能达不到通信速率。 | 复用 SIG-T02 的分段、电容和供电域，地址冲突另由 SIG-D01 核。 |
| SIG-C03 | 计算总线端接与偏置后的真实负载及空闲电平。 | 总线可能空闲误触发或驱动过载。 | 复用 SIG-T04 与相应接口条款，掉电负载另由 SIG-C04 核。 |
| SIG-C04 | 计算总线共模、地差及未供电节点的负载作用。 | 某节点掉电或地偏移时可能拖垮整条总线或造成注入。 | 复用 PWR-T06 和 SIG-T04，与 SIG-C08 共用注入路径证据。 |
| SIG-C05 | 核实 USB VBUS 的供入、控制、放电和保护配合。 | 端口可能错误供电、反灌或在事件后保持不允许的电压。 | 复用 SIG-D04 角色、PWR-T01 路径与 PRO-C01 保护结果。 |
| SIG-C07 | 计算实际负载下的逻辑电平和驱动能力。 | 静态电压看似相近，实际可能拉不动或越过脚上限。 | 复用 SIG-T04 方向及 DEV-C05 工作条件，掉电态由 SIG-C08 核。 |
| SIG-C08 | 追踪一个电源域掉电时的跨域电流及脚上电压。 | 信号可能反向供电、破坏关断状态或损伤输入结构。 | 复用 PWR-T01/T06 状态和 RST-T04 默认态，限流/钳位证据可复用 PRO-C01。 |
| SIG-C09 | 计算接口在实际时钟和负载条件下的采样时间裕量。 | 连接和电平正确仍可能在规定速率下误码。 | 复用 SIG-T04/C07 与 CLK-C01/D01；布局延迟约束移交下游。 |
| SIG-D01 | 核实 I²C 地址、地址脚及不同装配下的总线配置。 | 多个器件可能占用同一地址，或软件访问错误对象。 | 复用 SIG-T02 连通和 RST-E02 配置态，电气上拉由 SIG-C01 核。 |
| SIG-D02 | 核 DDR 校准和端接相关器件是否满足平台条款。 | 校准可能失败或接口不能达到要求的驱动/终端状态。 | 与 SIG-D03 共用平台版本，真实电源和脚义复用 PWR-T01、DEV-D02。 |
| SIG-D03 | 核 DDR 端接、基准及相关电源连接是否匹配平台。 | 存储接口可能参考错误、终端不当或训练失败。 | 与 SIG-D02 分工，电压和时序分别引用 DEV-C05、SIG-C09。 |
| SIG-D04 | 核 USB-C 实际角色、CC、线缆识别和能力声明。 | 端口可能误判连接、未经许可供电或超出线缆能力。 | 供 SIG-C05 确定 VBUS 状态，接口脚义由 DEV-D03 核。 |
| SIG-D06 | 核实调试、下载接口的脚义、电平和进入条件。 | 必要的调试或生产烧录可能无法执行，或连接工具时产生冲突。 | 复用 DEV-D03、SIG-C07，与 RST-D01 核恢复路径。 |
| SIG-D07 | 核 USB 物理层的连接、供电及外围条款。 | 设备可能不能枚举或在所需速率下不稳定。 | 复用 SIG-T01/T04 与 SIG-C05，板级信号质量另移交。 |
| SIG-D08 | 核串口与现场总线的收发器、方向和必要外围。 | 通信可能反向、端接错误或控制模式不成立。 | 复用 SIG-T04、SIG-C03/C04/C07 的连接和电气计算。 |
| SIG-D09 | 核 SPI/Flash 的片选、模式、供电和启动相关条款。 | 总线可能争用，或系统无法读取启动存储器。 | 复用 SIG-T04/C07/C09，启动配置与 RST-E02/T03 衔接。 |
| SIG-D10 | 核 eMMC/SD 的电源、数据、时钟及模式配置。 | 存储器可能无法初始化或在电压/速率切换时失效。 | 复用 PWR-T01、SIG-C07/C09 和 RST-T03。 |
| SIG-D11 | 核以太网 PHY、网变、中心抽头和外围的实际接法。 | 链路可能无法建立，或隔离及共模路径不符合要求。 | 复用 DEV-D02、SIG-T01/C07；隔离和对外防护由 PRO-D02/D03 核。 |
| SIG-D12 | 核射频器件或模组要求的供电、控制及射频端口配置。 | 模组可能不能启动、射频路径失配或性能无法达到要求。 | 复用 PWR-T01/C14、SIG-T04；实际射频布局和测试移交下游。 |
| SIG-D13 | 核主控引脚复用、分配和资源冲突。 | 两个功能可能争同一脚，或实际脚不支持声明功能。 | 复用 DEV-D02 和需求映射，实际方向与默认态交 SIG-T04、RST-T04。 |
| SIG-D14 | 核高速串行链路的耦合、端接、侧带和模式条款。 | 主数据通路看似正确，链路仍可能不能建立或切换状态。 | 复用 SIG-T01/T03/E02，布局和实际眼图作为下游验证。 |
| SIG-D15 | 核音视频接口的制式、偏置、端接及控制配置。 | 信号可能削顶、无声无图或与对端不兼容。 | 复用 SIG-T04/C07/C09，模拟范围与负载交 ANA-C01/C02。 |

# 适用性与最小充分证据

本页用于制定计划、复核自动候选和提出补证任务。规则总表是检查入口；实际判据由电路用途、
器件条款、受控需求和当前阶段决定。保留稳定编号及覆盖记录，不把一份通用模板的全部子条件
强加给每个器件、工况或功能包。

## 先回答三个问题

1. **是否适用？** 核实实际功能、拓扑、引脚复用、装配及状态。网名、引脚候选功能、位号前缀
   只能提示；明确声明或追踪证据才能确认。排除时引用具体事实，结果 NA；用途未确定则保留证据不足。
2. **这条判据需要什么？** 把连接存在、参数选择、边界计算和实物效果拆开。T 的连通判据不要求
   C 的完整应力模型；容量证据不足不推翻已证实的接法；后续温升未测不推翻已查清的绝限。
3. **现有资料能否回答？** 先用当前网表、官方资料、受控采购规格和已有计算完成判断。仅在
   一个具体缺口会改变结论时索取补证；文档已经在项目内但尚未读、算或录入，列审查待完成。

功能包展开后逐成员判断适用性。汇总项引用成员结果，不再次索取整套资料；统计唯一设计缺口
及任务，逐项台账数量只是覆盖规模。名称候选不展开成一组已确认适用的计算义务。
批量录入必须来自逐项判断，不能把某功能组的一段理由套到不同判据。共享计算可引用同一记录，
但每项须说明与本对象、额定值、工况的关系。已有资料未读算是 REVIEW_INCOMPLETE，
不冒充 EXTERNAL_DATA 或 DOWNSTREAM_VERIFICATION；此类未完成项在本轮关闭，放行始终阻断。

## 按实际用途选模型

| 候选规则/对象 | 适用判断与应查内容 |
|---|---|
| SDA/SCL 或多功能 GPIO | 确认本设计启用的模式及对端。只用于测试/编程时检查该接口的电平和接法；不强加运行 I²C 的地址、上拉或上升时间。用途未知不能直接 NA。 |
| DP/DM、差分命名 | 先查实际模式。充电识别脚按其检测/驱动条件查；真正高速数据链路才查共模、差分摆幅、端接和交流耦合。 |
| FB/ADJ | 先核传递关系。电阻分压、光耦电流反馈、内部设定和数字设定采用各自模型；FB 名称不证明存在分压 Vref。 |
| 分立晶体管 | MOS 开关的 RDS(on) 保证条件仅用于需要该导通电阻的工况。线性调整/源极跟随器查工作点、输出范围、VGS 绝限、损耗和适用 SOA；BJT 查基极驱动、VBE/VCE 与额定值。 |
| 电感/绕组 | 继电器等切换感性负载查关断续流。共模滤波器查额定/绝缘/滤波；变换器磁件查能量传递、复位和尖峰处理，不强制套一颗独立续流二极管。 |
| 输入保护 | 被动保险丝/MOV/NTC/桥堆查浪涌与保护协调；存在主动门限、MOS 或监测链才查对应 UVLO/OVLO、SOA、反接或检测使能。 |
| power_in 供电脚 | 先确认 VCC、HV 启动/检测、VBUS 等实际角色与原厂要求。电气类型不等于每脚必须有本地去耦；输出储能电容也不等同 IC 去耦。 |
| LDO 纹波、噪声与 PSRR | 逐状态追踪该输出实际供电的负载及耦合路径；板上存在 RF 器件不证明每路 LDO 都供应敏感负载。仅在原厂条款、受控需求或有据的负载敏感度适用时索取相应噪声目标；路径未知保留具体待核。该噪声子判据不适用不豁免输出范围、稳定性、额定和热损耗。 |
| 复位、启动、救援 | 外部 RESET、strap 或可编程平台存在且有相应要求时查其时序/恢复；电源 IC 的 UVLO、软启动和重试按实际条款查，不强加 SoC 的 RC 复位或 Maskrom。 |
| 关断、短路、保护状态 | 核规定的安全状态、应力、动作及恢复条件。允许停止调节时不再要求正常输出精度、纹波和闭环相位裕量。 |
| “缺少某项保护” | 先查路径上各 IC 自带的保护：PD 控制器的自适应 VO OVP 与阻断管、电源控制器的 FAULT/VCC OVP、过流计时等，按其门限和动作延时判断。门限由寄存器设定时归固件任务，不按“缺独立保护”报证据不足。 |
| 连续可调输出、多路供电取大 | PPS/AVS、宽输入等按整个连续范围扫描，重点算两路供电交接点附近的应力和线性损耗；只核两个端点不能判 PASS。 |
| 从参考设计派生的电路 | 列出全部偏离：拓扑或绕组抽头改接、器件额定降低、控制器替换（引脚耐压与内置功能不同时，照搬的外围防护可能不再够用）。每条按本设计条件复核；“与参考相同”只作线索。 |
| 不属原理图判定的需求 | 生产测试策略、知识交付、候选比较、尺寸优化等，判 NA 并写明范围，或作为移交；不记证据不足。 |
| 两端子或标准定义的连接器 | L/N 插脚、USB Type-C 插座等的脚义由标准规定，按标准核对即可，不另要结构化脚表。 |

一个排除理由只覆盖相应规则及状态，不能借此删除真实的保护、绝限、隔离或核心功能检查。

### 噪声路径资格

PWR-C14 的噪声子判据判 NA 前，按状态记录每个已识别敏感物理电源脚已资格化的完整上游供电、
可能耦合及返回路径和出处，以及本输出已核全部负载范围与适用噪声目标。跨磁珠、0Ω、开关、稳压器等
边界继续追踪；按 fitted 状态使用 NetGraph，PowerTree.source_of 只给来源候选，须人工核功能及完整性。
同网无命中、来源查询为空、状态或负载范围未闭合不能推出 NA；未知路径具体保留。存在本轨目标或敏感
耦合时仍核预算，噪声 NA 不关闭输出范围、稳定性、额定或热判据。

### 条款条件与任务约束

引用手册前先保留条件从句、目的和覆盖状态。“to ensure 某状态”的接法只证明达成该状态的条件，
不能脱离本项目是否需要该状态升为无条件缺陷；分别核默认状态、过渡过程、初始化策略和保证边界。
缺必需启动保证仍可为证据不足；实际违反适用绝限或无条件条款时继续判 FAIL。
图纸显示偏好与受控验收要求分别记录。任务要求保留完整网名、符号缓存或冻结区域时，建议先验证改法能
满足该约束；继承的全局标签不单凭显示偏好判错线，也不强制改 namespace。真实可读性或 ERC 违规另判。

## 模块本体、完整系统与制造核准

从需求与作者实际用途确定本轮承诺，再解释未知项；不要先套全系统或制造冻结模板，再要求公开项目补齐模板。
审查范围（只审本体，还是含指定对端的完整系统）以需求为准；需求未确定时按需求澄清（REQUIREMENT_OPEN）处理，
不由审查者自行认定为本体范围，再据此判 NA。

- **开放接口模块**：本体已有的电平转换、上拉、供电、关断及反灌路径仍须读算；据此给出端点所需的灌电流、
  门限、电容/速率、掉电兼容等集成约束。未指定外部主机/负载时，未知端点不自动成为本体缺陷或本轮待补证任务；
  需求已限定为本体范围时，整链兼容判据按该范围依据判 NA，保留本体计算，集成约束按 [结论与准出](verdicts-and-release.md#4-handoff-与集成约束) 记入 handoff。若需求已经指定对端或承诺兼容某标准/组合，仍须核保证条件，
  不能借“模块”或工作演示豁免。模块自身关键器件的参数缺口同样保留。
  外部主机未指定时，总线上拉范围、总线电容、主机电压窗口、灌电流等端点兼容判据不记证据不足：本体部分（板上上拉、电平转换、供电与反灌）读算后判 PASS/FAIL，主机侧条件写成集成约束（如“主机 VOL ≤ 0.4 V 时灌电流 ≥ 3 mA，总线电容 ≤ 400 pF”）。需求只点名主机系列（如“树莓派”）而未定具体型号时，用该系列公开规格的公共部分判定，型号间差异写成集成约束。
  外部负载未指定时同理：由本体器件额定、开关限流、调节能力等导出允许的负载包络（如 Iout_max 随 Vin 的关系），
  写成集成约束，不建需求澄清；需求或作者给出了额定负载时，按该负载审查。
- **名义功能与定量保证**：约某电压、某负载的功能主张，先核拓扑、标称设定及适用的工作证据；没有给出精度、
  温度或输入范围承诺时，不自行引入精密输出或全角点保证要求。手册某行测试条件不同，先判断是否影响当前主张，
  不是自动追加保证矩阵；涉及明确输出容限、临界绝限或保护保证时，适用的 Min/Max 仍不可省略。
  作者未承诺精度的输出轨，若给下游器件供电，下游的推荐工作范围（DEV-E02）与绝对最大额定构成隐含容限，
  仍按保证 Min/Max 核输出窗口（PWR-E01/PWR-C02），不能以“名义功能”判不适用。
  反之，需求无输出容限且板上无下游负载时，PWR-E01 实例及 PWR-C02（自动或人工生成）的输出窗口判据没有验收窗口：以需求和网表负载
  为 `applicability_evidence` 判 NA，在 rationale 记录名义设定计算，并把输出窗口写成集成约束；不因 Vref Min/Max
  未取得而保持证据不足。约束中的窗口用手头已有资料计算（资料已在手须读入）；不在手时写成公式及待代入的保证参数，
  由集成方按需取值，不因此建证据不足任务。“约 5V”等名义主张只用名义设定与工作证据核对，不据此自定允许偏差。
  NA 只覆盖输出窗口：PWR-C02 的调节能力（如 Boost 在 Vin_min、Iout_max 下的最大占空比与开关电流，Vin 接近或
  高于 Vout 时能否维持调节）及 PWR-C03 等非窗口判据仍按实际工作状态判定；同一 PWR-C02 实例兼含两类判据时，
  拆为窗口与调节能力两个实例分别记录。
- **物料身份与制造绑定**：保留符号/物理功能脚、极性及实际应力检查。普通指示灯、无源件或标准连接器缺完整
  采购料号，不自动阻断功能审查；按受控最小规格或有据边界（见 [通用件最弱档基准](commodity-floors.md)）判断，制造料号/焊盘绑定按实际复刻或冻结任务处理。
  若身份或参数未知会改变电气结论（如磁件饱和、补偿所需有效容量、临界钳位或安全等级），仍列具体的证据不足项。
- **正常拓扑行为**：停开关但输出仍有直流通路、没有独立保护等，先记录实际行为及使用约束；只有它违反需求
  内的关断、安全或故障响应要求时才判 FAIL。不得为此补造“输出必须归零”或固定保护级数要求。

功能证据只支持所覆盖的版本和工况，不能将上述范围裁定改写成全板/全工况 PASS。每条撤回的证据不足项注明不适用
主张及替代的本体检查/集成约束；真实疑点保留最小补证，不以减少台账数量为目标。

## 无源转接板的审查边界

先按作者用途与实际器件判定是在审转接板本体，还是含主机、线缆和负载的完整接口系统。
本体逐针核对信号、电源与返回路径、方向、装配和对端定义；连通正确不等于整条总线的电平、
灌电流、上升时间或掉电注入已合格。官方工作示例只支持其实际版本与组合，不能当全工况保证。

连接器的 POWER 类型是引脚传递电源的标记，不自动产生 IC 去耦义务。核实为无源连接器后，
可用现有 `intent.decoupling.components.<ref> = {"kind": "other", "citation": "已核对的器件与用途出处"}`
排除该去耦候选；保留顶层输入指纹与装配声明，重新生成计划。不得仅因 J/P 位号、板上没有电容
或希望减少证据不足项就排除，真实用电脚、未知器件和厂家要求的输入滤波仍独立审查。

已在 `intent.devices` 保存完整脚表的连接器，可另在 `intent.device_kinds` 声明原厂类型及原文页码，
经 datasheet audit 核验为 VERIFIED 后，默认 IC 去耦候选不再展开；原始脚表、身份、防护和接口检查仍保留。
依据及电源/返回脚写入去耦清单的 `non_decoupling_connectors`，未核验或仅靠符号/位号不能走此路径。
显式声明的端口输入电容条款和去耦 group 优先，仍逐状态展开；额定检查的补证目标是已贴电容，
连接器料号/针序及端口浪涌限制分别审查，不能移用为电容耐压、ESR 或有效容量证据。

无源转接板未承诺提供上拉、电平转换、复位或稳压时，不能因本板没有这些元件判缺陷。
把外部必要条件写成明确的集成约束：供电与逻辑域、上拉所在侧、允许的总线电容/速率、
电源针负载和未上电端口行为。按本体范围作出的不适用判断需引用范围依据；
实际要求审整个系统时，未知外部电路仍须补证，不能借“转接板”豁免。涉及本体额定载流、
器件身份等未证实主张仍保留具体缺口；不得把通用连接器手册直接当实际 BOM 的额定保证。

带检测接点的插座还要核内部接点：先用物理脚表识别检测端与壳地端的分组，再按插入/拔出等
实际状态逐一展开内部连通。两个外露检测端可能内部同组，不能因另一端未接就判断回路断开，
也不能把同组的另一检测端当地端硬接地。网络名、符号别名与物理脚编号分开记录；
内部连通只适用于已绑定的器件变体，不改写原网表，也不移用到独立双端开关。

## 证据够用的边界

- 参数取值回看原件的准确型号行、单位与数量级、合并单元格和脚注，记录可定位依据；
  文本提取可能错列或丢位时核原始图面。不能借同系列另一型号的参数，或把限值移用于表中未覆盖的工况。
- 原厂表头或注释已保证所需温度/电压/负载范围的 Min/Max，直接用于该范围；无需逐温度点
  另找证据。推荐工作温度证明允许工作，特定参数仍遵守其注明的条件。环境温度与实际结温分开。
- 正式边界比较使用适用的保证值。典型曲线可支持早期估算及有依据的 B 级工程推导，明确假设、
  裕量和后续验证；不能冒充 Min/Max 或证明临界绝限/保护保证。参数无全角保证时先看是否真正
  影响本判据，再确定需要的局部边界或验证，不自动索取全器件、全状态保证矩阵。
- 普通无源件可用受控最小规格（阻值、公差、耐压、温度等级等）完成相应选择检查；不统一要求
  每颗都有完整 MPN 手册。确有 DC bias、ESR、纹波电流、绝缘或寿命依赖的器件须有相应数据。
  安全关键器件仍明确其额定值、类别及必要认证要求，最终整机认证移交后续阶段。
- 官方脚表、同型号参数和共同采购规格只维护一份。相同事实引用原记录并核适用条件，不反复
  抄整篇手册；一个来源可靠且适用即可，不为补证数量要求重复来源。
- 最终烧录包、批量固件哈希和生产签署可在后续阶段提供；决定硬件正确性的协议能力、引脚
  复用、输出/保护参数、反馈及补偿配置在冻结前明确，不能整体推给固件或样机。
- “尽量小”“最好十年”等偏好先列目标和评估假设，不因缺硬阈值判 P1；成为明确必需验收条件
  后才按该条件判定。不得把模板示例数值当项目限值。

## 判“证据不足”之前先定界

先用已有资料完成适用模型下的计算和定界。采用局部参数、典型曲线或外推时，记录模型适用的
电流/电压、温度、工作区与拓扑范围、不利方向，以及误差和裕量依据；不能仅因加了余量就称为保守边界。
足以支持本条判据的工程推导可形成 B 级结论；缺口不影响结论时无需追加补证，也不强求每个工作点都有独立保证值。

- **齐纳管低电流**：核实际电流范围是否仍在所用模型的稳压区。单一测试电流下的 rdif 是局部参数，
  不能直接作为跨入低流拐点后的全区间斜率；用覆盖该区间的曲线、分段模型或有依据的斜率界限，计入温度与自热。
  只有局部数据时可先估算，但“拐点余量”须有来源或误差依据。
- **MOS 实际电流下的 VGS**：优先用实际电流、VDS、温度下的传输曲线或适用模型，并计入阈值与器件分散。
  原厂允许的阈值偏移法可用于工程推导，但须保留其假设；单点 gfs 不是从阈值到目标电流的全程常数，
  不能直接把 VGS(th) 上限加单点斜率外推当作保证边界。开关的 RDS(on) 保证条件仍独立核对。
- **吸收电阻功耗**：CV²f 用于每周期经电阻充、放电的简单 RC 估算，先核电压摆幅及充放电是否充分，
  并满足该模型的时间尺度条件（电压上升时间远小于 RC，RC 远小于有效充放电时长）。
  仅放电经电阻的相应 RCD 模型为 ½CV²f；钳位型按漏感能量、钳位电压及实际路径另算，不能统一套用。

- **二极管反向漏电**：25 ℃ 的 IR 最大值不是高温上界。按实际反压和最高结温读温度曲线；曲线是典型值时，
  用同一测试点“保证最大/典型”的比值外推并标为估计，不能用 25 ℃ 最大值代表全温。
- **额定字段缺失的通用件**：BOM 只给阻值/容值、封装或系列时，按 [通用件最弱档基准](commodity-floors.md) 定界：
  应力不超过最弱档的 50%，判 PASS（B），不需要具体料号；超过 50% 但该封装有满足降额的可订购档，判 INSUFFICIENT（DESIGN_OPEN），
  关闭条件写算出的最低额定（如“R8 ≥ 1 W、TCR ≤ 100 ppm”）；该封装可订购的最高档也不满足，按 FAIL 处理。
  MLCC 没有统一最弱耐压，按该文件的“陶瓷电容”一节处理：所需耐压在常规可订购范围内就判 PASS，
  并记入 BOM 约束。表外的类别，须引用所查目录及日期作为最弱档依据。
  BOM 缺额定字段本身只在 DEV-D04 记一条（附各器件的最低额定约束表），不在每颗器件上重复记证据不足；这一条按约束表中误选后果最严重的一项定级（如 18 V 轨误装 16 V 电容会击穿短路，至少 P2），不按“文档问题”一律定为 P3。
- **外部输入接入过冲**：先按需求确定源类型再选模型（见 [WCA 公式](wca-formulas.md) “输入接入过冲”）。
  只用硬电压源的 2·Vsrc 上界判“无法定界”是没有收紧边界；限流源模型只在输入电容远大于源侧电容时成立，在适用模型或有保证阻尼下仍超限才保留缺口。

- **保证条件与实际条件不同（单调外推）**：手册只在某一条件下给出保证值（如 VDD=2.5 V、25 ℃ 的 VOH/VOL，
  某电流下的压差），而手册自己的典型曲线显示该参数随条件单调变化、实际条件处在更有利的一侧时（更高的 CMOS 驱动电压、
  更小的负载电流、更低的温度下的漏电），可直接把较差条件下的保证值用于实际条件，结论为 B。
  曲线不单调、或实际条件在更不利一侧时，不能外推。
- **只有典型值的参数**：手册对该参数完全没有给出 min/max 时，按以下顺序取离散范围，写明出处：
  ① 同一手册中同类参数的 min/max 相对典型值的比例；② 同系列或前代器件对同一参数的保证范围（相似器件参考）；
  ③ 都没有时按典型值 ±30% 计。结论在整个范围内都不变，就判 PASS（B），并把“样机实测该参数”记为必需移交。
  方式②③只用于后果不超过 P2 的判据（功能裕量、效率、指示），它们是估算范围，不是本器件的保证值；可能造成器件损坏、过热、安全危害或保护失效的判据，
  仍须有本器件保证值，否则保留证据不足。
- **原厂典型应用等效**：电路与原厂手册或应用笔记中的典型应用一致（拓扑相同，器件值在原厂给出的范围内，
  输入与负载在原厂声明的条件内）时，该应用所决定的性能（稳压器稳定性、补偿、启动、内部基准配合外部分压）
  按原厂设计判定，结论为 B，引用原厂图号；器件应力、绝对最大额定和超出原厂条件的部分仍按本表计算。
- **脉冲与浪涌**：脉冲峰值功率不超过器件连续额定（降额后），峰值电压不超过最高工作电压时，不需要脉冲曲线即可判 PASS；
  超出才按脉冲宽度、重复率查脉冲降额曲线。
- **检流电阻**：料号未定时，按所在系列（或 BOM 写明的精度档）最差公差与 TCR 乘以实际温升，求阻值上下界；
  量程、限流点等判据在上下界内都成立就判 PASS（B）。只有电路声明测量精度、且精度预算依赖具体料号时，才要求确切料号。
- **隔离器件与安规**：需求没有声明安全隔离、认证或安规等级时，光耦、隔离器按功能隔离审查（CTR、传输、上拉、
  供电），绝缘耐压与爬电/电气间隙记 NA，并写成集成约束“本板不承担安全隔离”。需求声明了安全隔离时不放松：
  按需求的安规标准逐项核对；认证证书（UL/VDE/CQC）列明的系列额定可作为额定依据。

推出的界限按本条判据解释，不把估算、保证范围和可达工况混为一谈：
- **PASS（B）**：模型及边界适用，计入有依据的不确定性后仍满足判据；例如可信应力上界低于允许上限。
- **FAIL（B）**：证实存在要求覆盖的可达工况违反判据，或可信应力下界已违反限值；明确要求的保证条件
  已证实未满足时也可判 FAIL，但结论写“保证要求未满足”，不推断每件实物必然失效。
- **INSUFFICIENT**：现有模型或参数的不确定性可能改变结论。宽松的保守上界超过限值、或估算区间跨越限值，
  本身不证明实际超限；先尝试收紧边界，仍不能判定时只保留会改变判断的具体缺口。已经证实的 FAIL 不因此降回证据不足；自动 E 实例同样适用，见下文[自动证据计算的例外](#自动证据计算的例外)。

例如，适用条款明确要求保证电容下限，而身份已确认的实际物料规格不能保证该下限（只给上限，或公差、温度、
偏压修正后的保证下界低于要求）时，可判该保证要求未满足并提出改法；身份未确认时按下文[身份冲突与身份分支](#身份冲突与身份分支)处理，
不以候选资料判电气 FAIL；
若可信应力下界已违反器件额定或项目降额要求，且未计项只会增大应力，也无需等待所有参数齐全再判 FAIL。
等于限值是否违反，按条款是否允许等号及项目裕量要求判断。

原厂依据与适用范围：
- [Vishay Silicon Zener Diodes，pp.1–2](https://www.vishay.com/docs/84117/84117.pdf)：动态电阻随电流变化，低电流区明显增大；直流变化还需计入热效应。
- [Infineon MOSFET Datasheet Explanation，§2.7–2.8](https://www.infineon.com/assets/row/public/documents/24/42/infineon-mosfet-optimos-datasheet-explanation-applicationnotes-en.pdf)：传输曲线、阈值平移近似与工作点相关的跨导。
- [Nexperia TN00008，§13.3 与 Fig.39](https://assets.nexperia.com/documents/technical-note/TN00008.pdf)：带假设的最坏器件估算；工程信心与生产测试保证分开。
- [ADI Snubber Circuits](https://www.analog.com/en/resources/technical-articles/snubber-circuits-suppress-voltage-transient-spikes.html)：Simple RC、Rate-of-Rise Control RCD 与 RCD Clamp 的不同能量路径和时间常数条件。

PDF 文本提取可能把 µ 显示成 m（如“30 ms”实为 30 µs）。决定结论的时间、电流数值要对照渲染页核单位。

## 身份冲突与身份分支

PART/VALUE 冲突，或图面/BOM 与链接资料互相矛盾时，建立身份分支，可按候选继续分析，但不得认定候选为实际物料：

- 记录不一致本身判 DEV-D04 FAIL（数据缺陷，按影响定级）；
- 依赖实际物料参数的电气判据保持 INSUFFICIENT，逐分支给条件结论（如“若实为 Y5V 则有效容量不满足”），
  补证为确定实际料号；
- 只有全部候选分支都违反判据时，才可判该电气判据 FAIL。
- 全部候选分支都满足判据时，判 PASS（B），结论写明“实际物料在上述候选内即成立”，并把候选范围写入 BOM 约束。

身份没有冲突、只是档位或后缀未定（如光耦 CTR 分档、温度等级后缀、通用 NPN/肖特基、同系列不同代）时，按系列中对本判据最不利的档位（CTR 最低档、温度范围最窄档、手册中最差的保证值）计算：最差档仍满足，就判 PASS（B），不再要求确定具体后缀；最差档不满足，才把“须选某档以上”作为证据不足或修改任务。差异只影响固件配置（如 I²C 地址后缀、上电默认寄存器）时，不记证据不足：电气检查按各后缀分别成立判定，把“固件配置须与实装后缀一致”写成集成约束。

一个可信原厂文档可确认器件类别；库名和商城转引同一 PDF 不算两个独立证据。

## 自动证据计算的例外

自动证据计算（方式 E）在资料未 AVAILABLE、指纹过期或模型缺失时保持证据不足，规则见 [证据计算契约](datasheets.md#二证据计算契约evidence-schema_version-2)。两个例外：

- **边界已证明违反**：已有保证值或可信边界已证明违反判据，且缺失参数取任何允许值都不能改变结论时，该 E 实例与
  同一判据的人工检查同判 FAIL；证据写明所用边界及结论不依赖缺失参数的理由，同一根因共用一个 finding；补齐资料后
  复核数值，不降回证据不足。
- **没有验收窗口的名义输出**：需求无输出容限且板上无下游负载时，PWR-E01 及 PWR-C02 的输出窗口判据判 NA，
  做法见上文[名义功能与定量保证](#模块本体完整系统与制造核准)；调节能力等非窗口判据照常审查。

## 原定资料取不到时

按本条判据**逐参数补证与替代**，不把“缺整本 datasheet”等同于“所有判断都无法进行”。
先确定需要证明的参数、工况与验收窗口，再选择能关闭缺口的路径；不必穷尽所有路径。

1. **换渠道取同一型号**：查原厂、授权分销商、LCSC/立创及存档/镜像，核完整后缀、封装、
   档位与版本。访问被拒或超时就换渠道，记录失败原因；镜像文档也须核实原厂出处和身份。
2. **取同型号的其他原厂证据**：应用笔记、评估板指南、勘误、技术支持答复可证明其中明确
   覆盖的参数或接法；核文档适用型号、工况和版本。示例电路或典型值不能自动升级为保证值。
3. **取供应商受控规格**：采购规格、承认书或定制件图纸可用于其明确保证的项目，尤其是
   磁性件和无源器件；记录供应商、料号/版本、适用批次或采购约束，不用未确认报价参数代替。
4. **从电路反算要求，再取最小补证**：先算允许的参数区间，例如指定栅压/结温下的最大
   RDS(on)、所需耐压或漏电流上限，再补能证明目标器件落入区间的证据。反算结果是选型
   要求，不是器件实有参数；缺口只写会改变结论的参数、工况和取得方法。
5. **按参数借用相似器件资料**：用于建立候选模型、探索参数范围和敏感度，逐项说明
   器件结构、功能、驱动/偏置、温度及测试条件的可比性。多个相似型号的数值包络仍只是
   探索范围，不能直接当作原器件保证范围；同封装、同额定电压或同系列名称本身不证明等效。
6. **实测与模型校准**：用目标器件的测量约束关键参数，记录样本/批次、工况、测量误差及
   覆盖范围。校准后的仿真用于已建模行为；样本结果、典型模型不能证明未覆盖的全温/全批次，
   未建模的保护、热行为或失效机理仍需独立证据。尚未实测时列验证任务，不写成已证实。
7. **建议换成有资料的器件或改电路**：列满足反算要求的替代件及引脚、封装、驱动、额定值和动态行为
   差异，或让现有器件回到保证条件内的电路改法，给出 BOM/原理图修改与复验条件，写进任务的
   `design_option`。只有设计实际修改并复验后，才能用新证据关闭对应项；建议本身不改变当前结论。
   器件被用在原厂测试条件之外（如齐纳低于测试电流、光耦低于测试 IF）时，原厂通常不会补发保证，
   这类缺口优先推荐改设计（`preference: DESIGN_FIRST`），不要只写“向原厂索取”。

借用资料时，在已有计算记录中逐参数标明“本器件已确认 / 相似器件参考 / 分析假设”，
附来源页码、适用工况、采用区间、不利方向及敏感度结果，由 checks.evidence/rationale 引用。
不新增必填 schema。相似性推断的置信度不高于 B，但 B 标签本身不足以支持 PASS/FAIL：
只有目标器件的适用范围有依据，且不确定性不会改变本条结论，或该判据已证明不依赖未知参数，
才按前节规则下结论。否则只给条件计算，受影响主张保留 INSUFFICIENT/C，并列最小补证。
不能用相似器件证明原器件身份、安规认证、绝对最大额定值或未获证实的保证参数。
同型号原厂证据与受控规格按其实际覆盖范围定置信度，不因缺整本手册一律降为 B。

资料覆盖审计如实保留 NOT_FOUND；人工 T/C/D 判断与自动 E 保证值契约分开。
替代资料不能把本物料改成 AVAILABLE，也不能填进 evidence.json 冒充本器件保证值。
自动 E 仍缺输入时保留证据不足；人工计算可支持其有证据的具体主张，须关联原检查并说明覆盖差异，
不能借新增人工项删掉原检查、隐藏缺口或绕过冻结闸门。

## 复核每条“证据不足”

沿用四态检查结果；需求澄清按 [独立需求澄清协议](requirement-clarifications.md) 单独报告。
下表为检查尚不能判断的原因，不是独立问题数量：

| 原因 | 可选 `gap_cause` | 处理 |
|---|---|---|
| 需求待澄清 | REQUIREMENT_OPEN | 判据所依赖的需求缺失、含糊、冲突或待确认，例如输入电压范围与频率、环境（海拔、气候）、适用标准与抗扰度等级、能效版本、目标市场认证。不当作缺资料，反馈给需求责任方：按独立需求澄清协议记录唯一问题、已核输入、待决内容和关闭依据；归本轮任务（`design_iteration`）。需求定了但标准正文未取得，属 EXTERNAL_DATA。需求文档里标为未定（OPEN）的条目在 intent 中写 `status: OPEN`（暂缓（DEFERRED）写 `status: DEFERRED`，归“用户明确暂缓”），由校验强制归入本类；只依赖该需求的其他检查（如按降额点判定的热敏链路）由审查者同样归入本类。复审时不得沿用上一版的 gap_cause，必须逐条重新归类。 |
| 真实资料缺口 | EXTERNAL_DATA | 指出缺哪一参数/身份/工况、影响哪一判断，列最小取得方法和关闭阶段。 |
| 设计尚未决定 | DESIGN_OPEN | 列需定型的规格/配置及约束；AI 先完成可做的选型/计算，到真实取舍点再请人决策。 |
| 审查尚未完成 | REVIEW_INCOMPLETE | 明示还未执行的阅读、计算或录入并继续做，不说成外部资料不存在。临时台账可记证据不足，不能据此宣称审查完成。 |
| 后续设计/验证 | DOWNSTREAM_VERIFICATION | 把原理图已能判定的部分单独结论，结构、PCB、样机部分列移交约束与验证方法。 |
| 用户明确暂缓 | USER_DEFERRED | 引用用户的暂缓指示，写明恢复时要补的内容；不当作缺资料。 |
| 检查口径过严 | 不设 | 现有资料已够判定，或不属原理图判定范围：改判 PASS/NA 或改为移交，不保留证据不足。 |
| 不适用/重复汇总 | 不设 | 有依据则 NA；汇总引用具体成员缺口，不生成重复补证任务。 |

一个缺口影响多项检查时，逐项判断这一项的结论会不会因缺口而改变：不会改变的（如缺的是额定值，而本项只核连接与极性）照常判 PASS/FAIL，只在结论真正取决于缺口的检查上记证据不足，并在报告中按缺口归并，不按检查条数放大。

报告按原因给出受影响检查条数，需求澄清按唯一问题另计，回答“哪些要设计者先定需求、哪些是真缺资料、哪些是设计或审查没做完”。

每条保留的 INSUFFICIENT，其 missing_inputs 写具体缺口，例如：
“缺输入浪涌电流及持续时间，无法比较保险丝与桥堆 I²t”；不要写“缺完整手册/全部应力证据”。
在 rationale 写已有事实、尚不能判断的主张及实际影响；在 work_item 写取得方法、承担角色、
关闭阶段和验收。已有字段足够时只链接共同记录；缺字段或导出工具限制不是新的电气缺陷。

“移交后续设计”明确写 PCB、结构、固件或样机阶段，所需输入、设计约束和关闭方法。
例如：硬件给最大损耗/允许结温；结构确定散热路径和高温降额；样机核实温升。
热判据按 [热相关审查边界](verdicts-and-release.md#热相关审查边界) 拆分：缺负载、适用额定值或
温度保证条件可能影响电气判断；缺板上热阻、热仿真或温升实测本身不构成原理图电气缺口。
日常设计不等待接收签署才继续；实际移交与冻结依照 [verdicts-and-release.md](verdicts-and-release.md) 的独立闸门，
OPEN 在正文写“待后续团队处理”，不得暗示已被接收或已经验证。

## 能否用电路修改消除缺口

把 INSUFFICIENT 归为 EXTERNAL_DATA 或 DESIGN_OPEN 之前，再问一次：改原理图能不能让这条判据
只依赖已有的保证值？常见的情形：

- 器件工作点落在手册保证条件之外：改偏置、换有对应条件保证的器件，或换不依赖该参数的拓扑；
- 余量只差一点：换压降/漏电更小的器件、调整分压或门限，让最坏值落在判据内；
- 规格只有标称类别：定下有曲线和额定值的确切料号（这本是设计动作，原因写 DESIGN_OPEN）；
- 参考设计里有更简单的已验证做法：列出偏离点和改回的代价。

能改就在任务里写 `design_option`（`PROPOSED`）：按改后电路逐条说明规避了什么问题、哪些检查因此
可以闭合、还剩什么，以及新增的代价（成本、体积、损耗、热、需要改的规格）。要用到的计算按已有资料
做完；需要改已确认规格的，写成待用户决定的前提，不自行改需求。确实无法靠改图消除的（磁件供应商
承认、固件配置、只能实测的量）写 `NONE` 和原因。

## 交付前的必要性复核

逐条检查未决项：规则确实适用吗？现有资料读过/算过吗？缺口确实改变本判据吗？已在另一
任务或成员项中要求了吗？应在本轮、冻结前还是后续解决？答不清时先修正计划或继续审查。
真实电气缺口仍保留；不能为压低数量改成 PASS，也不能为补齐模板扩大实际审查范围。

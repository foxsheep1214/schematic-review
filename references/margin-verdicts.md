# 余量判定规则

> 读者：审查员。

一条写出来的余量怎样判：合格、合格但有风险、不合格。本文件只管这一步（2026-10-27，用户：架构按六个问题分阶段重理）；
限值从哪来见[工作点定界表](bounding-table.md)，应力怎么算见 [WCA](wca-formulas.md)，不合格和缺口怎样定级见[结论与准出](verdicts-and-release.md)。
余量的字段写法见[功能判定](results-format.md#功能判定functions)。

## 比什么

- 余量是额定与最坏应力之差。额定取最坏工作温度下的保证值（降额规范 R4：手册给温度折减曲线的先按曲线修正）；
  设计约束（DESIGN_CONSTRAINT）按约束的不利端。**降额不扣进限值**：降额值只决定有没有应力风险。
- `comparison` 为 GE 时零余量算满足，GT 时不算；等号是否允许按条款原文。
- 负向额定（关断负栅压）按幅值比较（降额规范 R8）。
- 瞬态比瞬态额定、持续比持续额定；瞬态的降额值同样只定应力风险。

## 判定

| 余量 | 结论 |
|---|---|
| 确会出现的工况或完整最坏范围超出额定 | 不合格：记失败项，按后果定级 |
| 只是可信最坏上界超出额定，边界过宽 | 不判不合格：指出哪个输入取得松，收紧再判（[结论与准出](verdicts-and-release.md) 定级步骤 4） |
| 保证值下在额定内，超过本等级降额值 | 合格，但有风险（应力）：按[器件应力规范](stress-spec.md) |
| 只靠估算过关（定界表的格允许估算） | 合格，但有风险（环境适应性、寿命、一致性，取格的“估算对应的风险”）；C 级证据 |
| 寿命检查项凭估算过关 | 合格，但有风险（寿命）；改法取它的 BOM 约束 |
| 保证值下在额定内，且不超过降额值 | 合格 |

- 明确要求的保证条件已证实未满足（如身份已确认的物料规格保证不了所要求的电容下限）判不合格，结论写“保证要求未满足”，
  不推断每件实物必然失效；身份未确认时按[身份冲突与身份分支](evidence-proportionality.md#身份冲突与身份分支)，不以候选资料判不合格。
- 可信应力下界已超额定、未计项只会增大应力时，不等参数齐全就判不合格；宽松上界越限或估算区间跨越限值不证明超限，先收紧边界，
  仍判不了只留会改变结论的具体缺口。已证实的不合格不降回证据不足（E 检查项同样，见[保证值核对的例外](evidence-proportionality.md#保证值核对的例外)）。
- 算出了余量就下结论，不能一边算出余量一边保留证据不足；余量够不够只看上表，不看审查员自设的倍数。
- 风险不限制定稿，门禁 `risks` 逐条列出，报告附录单列“风险清单”。
- 降额规范对这类器件、这个参数有规则的，余量点名 `basis.derating_rule`，门禁按项目等级核（见器件应力规范）。
  SR 门禁另核规则选得对不对（2026-10-28，用户：按推荐修改）：余量单位与规则参数的量纲、限值条款点名的端子对（VDS/VGS/VCE…）与规则参数不符的拒收；器件身份（型号、值、符号）写明了技术（Si/GaN/SiC/IGBT）而规则是别的技术的拒收；稳态规则配瞬态措辞（或反之）、身份没写技术的，只出提示 `DERATING_RULE_FIT`。

## 没有料号的常规件

BOM 只有封装或通用值时，额定取[通用件最弱档](commodity-floors.md#定界)：

| 应力相对最弱档 | 结论 |
|---|---|
| ≤ 50%，且实际受控采购范围被最弱档资料覆盖 | 合格（B），理由写采购范围、目录条件及“低于该范围最弱档 X 的 50%” |
| 采购范围未受控：片式电阻功率 ≤ 最弱档的 50% 且电压 ≤ 50%；MLCC 按可订购档 | 合格（B），理由写“低于未受控门限”；功率超过最弱档 25% 时附 BOM 约束 |
| > 50%，但该封装/系列有满足要求的可订购档（附目录） | 合格（B），最低额定写进 DEV-D04 的 BOM 约束 |
| > 50%，且可订购的最高档也不满足 | 不合格：换封装/系列或改电路；须引用覆盖该封装类别的目录或标准证明没有更高档 |

- 功耗要考虑（最坏功耗超过 BOM 已写字段能买到的最弱件的降额值）而 BOM 没写额定功率的电阻，必须写明功率等级，
  门禁按预判核（[计划预判](commodity-floors.md#计划预判dev-c01-逐颗检查项)）。
- **BOM 约束的最低额定按项目降额等级取**（2026-10-27，用户：BOM 最低额定按项目降额等级取值）：额定 ≥ 最坏应力 ÷ 本等级取值
  （片式电阻功率取 RES-SMD-P，其余按降额规范对应的规则）；项目没定降额等级时取 2 倍应力。
- 50% 是计划预判的门限：电阻实际功率通常不超过额定的 50%（知识库《电阻降额设计》），计划据此决定是否逐颗出 DEV-C01、
  是否给建议合格。它不是降额判定：选定器件后按项目等级的降额值判。
- 环境温度高于 70 ℃ 时，电阻额定先按降额曲线折算（典型：70 ℃ 起线性降到 125/155 ℃ 时为 0）。
- 只用于连续应力。脉冲、浪涌、精密检流、安规与隔离件不适用，仍按具体资料审查；应力本身仍按实际最坏工况（最高电压、阻值下限）算。
- **买错仍在额定内、只缺降额余量**的 BOM 约束定 P3（[定级](verdicts-and-release.md#bom-约束怎么定级)）：它是 BOM 一侧的应力风险——
  器件选定后同样的情形记应力风险、不挡定稿；作为 BOM 约束它是要写进 BOM 的要求，所以带等级。

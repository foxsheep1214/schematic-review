# 原理图审查报告模板 V2

报告应让设计者先知道结论、先改哪里，再能按证据复核。项目审查目录同时保存机器台账与证据。
完整字段以 [review-results-schema.md](review-results-schema.md) 为准；分级以
[severity-calibration.md](severity-calibration.md) 为准。不能用长模板掩盖没执行的检查。

## 1. 结论及版本

- 对象：板卡/原理图版本、装配配置、输入哈希清单、网表与 PDF 一致性、首审/复审基线。
- 结论：准出 / 有条件准出 / 不准出，仅针对原理图冻结进入 PCB Layout。
- 已确认：P0 __ / P1 __ / P2 __ / P3 __（唯一缺陷 ID 数，注明可选改善数量）。
- 待核：__，其中潜在 P0/P1 __；开放阻断 __；必需 HANDOFF 未接收 __。
- 最优先修改/补证项目与具体原因；规格受限、仅 PDF/部分执行在此明示。
- 不能把“关键前提尚未关闭”写成可立即进入 Layout 的有条件准出。

## 2. 全部问题总表（按 P0→P3）

| ID | 等级 | 页/位号/物理脚/网络 | 已确认偏离 | 触发条件/影响 | 建议动作 | 复验标准 | 状态 |
|---|---|---|---|---|---|---|---|

同一根因合并 ID，保留受影响各检查链接。建议、文档问题也要有位置，不能只写“注意上拉”。

## 3. 每项发现详细记录

    F-xxx / P0–P3 / 标题
    当前结果、证据置信度、关闭状态、关联 REQ/检查 ID：
    位置：实际 PDF 页 + 页名 + 位号.物理脚 + 网络
    观察事实：当前连接/值/贴装及原始来源定位
    判据：文档名/版本/页码或条款/表号，适用模式与必要强制词
    推导：公式/拓扑/条件→不满足什么，范围与置信度
    影响与定级理由：功能/器件/外部设备，触发工况，已有独立保护
    修改：旧→新（网/物理脚/值/精度/额定/贴装），有条件方案与待定输入
    修改后校核：参数全角、关联电源/时序/保护/接口变化
    复验：可执行断言/检查、通过标准、需下游验证的部分

原始 datasheet 原文只引用必要短句并保留定位。补取来源另记 URL/版本/获取日期。
不可凭材料不足提出唯一确定替代料；不可用“软件注意”替代必需硬件保证。

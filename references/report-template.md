# 原理图审查报告模板

默认正文只写结论和需要处理的事项，详细台账与计算放可定位的附录；无内容不设空节。
结果字段以 [结果契约](review-results-schema.md) 为准，分级与准出以
[severity-calibration.md](severity-calibration.md) 为准。报告、台账和证据保存在项目审查目录。

## 1. 结论与范围

写明板卡/原理图版本、装配配置和首审/复审基线，链接输入清单，说明 PDF/网表同版核对结果。
按本轮范围与阶段给出结论：非冻结阶段（design_iteration / prototype_verification）说明已证实功能、真实缺陷、
仍影响本体判断的疑点和集成约束；
申请原理图冻结时才给出可冻结、有条件冻结或不可冻结及主要原因，有条件冻结须有实际接受记录。
审查未完成时明确“审查进行中”，仅交进度和剩余工作，不能把已填台账数量当作完成依据。
仅 PDF、外部缺证等限制直接说明其影响，不用长篇通用免责声明。

电气结论依据已核实的证据；`valid=true` 不另作“审查通过”展示。工具保留的 `release` 是冻结闸门，未申请冻结时
不能把它作为非冻结阶段的总判定，也不能反过来将真实电气阻断项改成 PASS。
日常设计说明本轮先做什么；申请冻结时遵守 `review-gate.json` 的阻断结果。准出范围是原理图进入 PCB Layout。
复审概括本轮新增、修复、撤回和仍开放的事项，历史数量不混入当前缺陷。

结论后固定列一组计数，每类单独一行，为 0 也写出（写“FAIL 0”，不写“无 FAIL”或省略）；
一行结论和 README 摘要重复同一组数字：

| 计数类别 | 取值 | 来源 |
|---|---|---|
| 检查结果 PASS / FAIL / INSUFFICIENT / NA | 各类检查行数 | `review-gate.json` 的 `summary.results` |
| 确认缺陷 P0 / P1 / P2 / P3 | 唯一缺陷数 | `summary.by_severity` |
| 待核项潜在等级 P0 / P1 / P2 / P3 | INSUFFICIENT 检查行数 | `review-results.json` 中 INSUFFICIENT 行的 `potential_severity` |
| 移交状态 OPEN / ACCEPTED / VERIFIED | 移交检查数 | `categorized_summary.handoffs_by_state` |

工具输出省略的类别按 0 补齐。检查行数、唯一缺陷数和移交数口径不同，不相加。

## 2. 处理清单

按紧迫性列全部需处理事项。同一根因或独立决定一行，通过“类别”区分电气缺陷、需求澄清、
证据/设计缺口、审查待完成、下游移交和可选改善；有需要时分组，不强制分别建重复表格。

| ID / 类别 | 位置、问题及依据 | 影响 / 冻结影响 | 建议及下一步 | 关闭条件 / 时点 / 状态 |
|---|---|---|---|---|

- 电气缺陷标 P0–P3，写清不满足的判据、工况和影响，链接原始证据与计算。按
  [修改说明](remediation-guide.md) 给可执行的旧→新、接法/物理脚、参数依据、联动复核和通过标准；
  可在明细中展开，正文不重复抄写结构化字段。
- 需求澄清保留独立 ID，写已核输入、待决定内容/建议、责任方和关闭依据；详情按
  [需求澄清协议](requirement-clarifications.md) 链接。未定需求不套缺陷等级，不计入缺陷总数。
- 待核说明已知什么、具体缺什么、影响哪个判断、如何关闭。先完成现有资料支持的分析，
  按 [最小充分证据](evidence-proportionality.md) 索取必要输入；同一补证动作只列一次。
- 下游移交写接收角色、定量约束、验证方法与阶段，引用真实接收记录；原理图已能判断的电气前提
  仍须完成。热实现、PCB、结构和样机事项按 [范围边界](scope-boundary.md) 处理。
- 同一问题关联多个检查只统计一次；保留关联 ID。第 1 节固定计数之外，需要时分别统计缺陷、澄清、
  待办和移交，不将检查行数或质量提示数称为缺陷数。覆盖统计和工具诊断留在附录。

交付前确认每条不通过或待关闭事项都有明确建议与关闭条件；不得用“不通过/待验证/参考手册”代替动作。缺参数时给取得方法及条件方案，不编造定值。

## 3. 证据与追溯附录

可直接链接已有持久化文件，不要求再制作一套同内容表格。保留以下资料以便追溯：

- 输入版本/哈希、需求、装配与规则指纹；PDF 页码/页名/网表路径映射，未知标 UNKNOWN。
- 全量检查台账：对象、判据、状态/结果、证据、计算、关联 finding/澄清/任务/移交。
  冷热候选处置、覆盖和未完成项映射均保留，不以摘要代替检查。
- 实际计算、图面记录和修改明细。模型、输入公差/出处、边界结果及验收窗口可重现；
  相似器件参数、反算要求与本器件事实分清，可能改变结论的假设保留待核。
- 复审的 Diff、历史 ID 到本轮结论的映射、关闭/撤回依据及复验证据；未执行复验不能关闭。
- `review-gate.json` 和必要的更正依据。质量提示在已有证据记录中注明更正或共享证明的适用范围，
  不另建一套“语义审查报告”。来源与判据未变且依据已经核实的项不因重复提示反复审查。

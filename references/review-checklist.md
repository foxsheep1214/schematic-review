# 原理图审查通用检查表（按电路域）

适用于任何板卡的 L5 检查表骨架。按项目裁剪；平台专属规则库（SoC 原厂 / 平台方 / 认证机构）附在本文件末尾模板中，按项目替换。每条判定后标 ✓/✗/NA + 证据。

## 1. 电源输入与保护
- [ ] 输入保险丝/PTC 额定与降额（自印降额规范逐项核对）
- [ ] 输入 TVS：Vrwm > 工作电压上限；钳位电压 < 后级器件绝对最大额定（含热插拔芯片、MOSFET VDS）
- [ ] 防反接电路（MOSFET 理想二极管/二极管）方向与栅极钳位
- [ ] 热插拔：UVLO/OVLO 窗口与母线匹配；限流点 vs 系统需求；浪涌 I=C·dV/dt vs 源端限制；输入电容总量 vs 平台限制（如 ≤500µF）
- [ ] 大电流路径载流：连接器单针额定、走线、并针

## 2. DCDC / LDO（每颗必过）
- [ ] FB 分压代入实际 E96 阻值复算输出电压（含电阻公差 + VFB 公差后的窗口），与目标轨和负载器件推荐工作条件（min/typ/max）比对
- [ ] Vref 基准值以 datasheet 为准（不写印象值）
- [ ] EN：有效极性 vs 上/下拉；EN 耐压 vs 所接轨（先读 Abs Max）
- [ ] 软启动/浪涌；min on-time 核算（高频+大降压比时）
- [ ] 电感 Isat/DCR、输出电容总量与 ESR、补偿网络接法（对 AGND 还是输出）
- [ ] 自印降额规范（如 DCDC 80%）执行核对

## 3. 电压监控 / 复位芯片
- [ ] 器件档位从订货表/丝印确认（固定阈值版本 vs 可调；−5%/−10% 档）
- [ ] 每路动作点复算：VTHx = Vth_pin × (R1+R2)/R2；**下臂串联电阻求和**；给 typ + min/max 范围
- [ ] 被监测轨确认（同名不同域的轨分清）
- [ ] 动作点 vs 页面注释意图、vs 被保护器件的工作下限（报警太晚=监测失效）
- [ ] 输出链：开漏上拉、上拉电源域、串联/滤波、到主控的终点

## 4. 时钟
- [ ] 晶振 CL 与外接电容匹配（等效 CL = C1×C2/(C1+C2) + Cstray；按晶振料号 CL 核算，不看"典型印象值"）
- [ ] 反馈电阻、串联电阻按 datasheet/参考设计
- [ ] RTC 晶振 32.768kHz（丝印笔误高频）；外部 RTC 备份电池/超级电容充电电压 < 上限
- [ ] 有源振荡器使能脚/电平域

## 5. 复位与启动配置
- [ ] RC 复位 τ 满足最小复位脉宽；复位链每一跳连通
- [ ] 启动模式/BOOT 脚默认电平有确定驱动（上电采样窗口不悬空）
- [ ] strap 采样电平：节点上 LED/其他上拉对采样窗口分压的影响
- [ ] Recovery/Maskrom 等救砖通道存在

## 6. 主控 / SoC
- [ ] 全部电源球有驱动（L0-05）、全部 VSS 球入地（L0-06）
- [ ] 各 IO 电源域实际电压 vs 相连外设电平
- [ ] 去耦电容与参考设计一致性
- [ ] 未用 PHY/外设电源脚处置按平台规范（悬空/接地/关闭）
- [ ] 调试口（UART/JTAG/SWD）可达、串阻、ESD

## 7. 存储
- [ ] eMMC/SD：IO 电平、CMD 上拉、CLK/STROBE 串阻、测试点位置
- [ ] DDR：ZQ 阻值/精度/接法（接 VDDQ 非地）、各 VDDQ 域电平
- [ ] SPI Flash：VCC 域、上拉、写保护

## 8. 接口（逐路核对双向连通 + 方向语义）
- [ ] USB：REXT、DP/DM 串阻、VBUS 检测、ID、ESD 在活线上
- [ ] UART/RS232/RS485：TX/RX 方向回官方引脚表复述；端接、偏置、防护
- [ ] CAN：收发器供电/VIO、STBY/EN 默认态、120Ω 端接策略（本端/对端书面明确）、隔离方案
- [ ] I2C：上拉值与电源域、地址冲突、总线只留一组上拉
- [ ] SPI：CS/时钟极性、串阻
- [ ] 以太网：MDI 差分对 P/N、变压器 CT 端接、Bob Smith 75R+1nF/2kV、MDIO 上拉、PHY 复位与 strap
- [ ] RF/模组：天线路径默认通断、供电电容阵总量 vs 规格书最小值、开关机/复位驱动 vs 参考设计、SIM 卡 ESD 与上拉

## 9. 电平域与电平转换
- [ ] 跨电压接口（1.8V↔3.3V 等）有转换器或书面确认两端同域
- [ ] 上拉电阻电源域 = 信号两端域的较高者（防倒灌）
- [ ] 网络命名与电平一致（DBG_*_3V3 实为 1.8V 属误导）

## 10. 防护链（逐段点名）
- [ ] 雷击/浪涌（GDT/TSS）→ ESD → 端接 → 隔离，段间配合（动作电压、能量）
- [ ] ESD 器件挂在活线上（L0-10）
- [ ] 跨隔离带爬电距离、跨接电容耐压
- [ ] 对外连接器每针防护考虑

## 11. 无源器件
- [ ] 电阻功耗 P=U²/R（>20V 分压每颗算）≤ 封装额定 50-70%
- [ ] 电容耐压降额（自印规范，如 50%）；MLCC 直流偏压有效容量
- [ ] 精密用途（分压/采样/ZQ）精度 1%
- [ ] 电解电容寿命核算（高温满载场景换固态）

## 12. 连接器
- [ ] pinout 与对端定义逐针核对（板内自洽 ≠ 对端正确）
- [ ] 载流（单针额定 × 并针数 ≥ 设计电流）
- [ ] 防误插、pin1 标识
- [ ] 未用针处置（悬空 vs 接地，平台规则）

## 13. 热
- [ ] 各发热器件功耗估算与散热路径（模组、DCDC、主控、PHY）
- [ ] 温度传感器位置合理性
- [ ] 外壳/环境温度约束传导到器件结温

## 14. 测试点与可生产性
- [ ] 关键 rail、strap 点、调试信号有 TP 且 Layout 可触探
- [ ] BOM 值字段无异常字符串（4.7F 类笔误）
- [ ] 库卫生：符号名 = 实物 MPN（防采购误读）

## 15. 文档与图纸卫生
- [ ] 页面注释与实贴 BOM 一致（注释=意图，BOM=现实，都核）
- [ ] 遗留命名/注释清理（换方案残留）
- [ ] 网络命名规范、无双胞胎名
- [ ] 图框信息、版本一致性（PDF vs 网表导出时间）
- [ ] 需求/规格书与原理图参数口径统一（电流/电压数字唯一来源）

## 附：平台规则库模板（按项目构建，示例为 Rockchip 摘要）

把平台官方 checklist/HDG/PinOut 中**可判定条目**逐条转为检查项，注明出处版本：

```
### Rockchip（RK35xx）示例条目（出处：官方 Schematic Review Checklist）
- 晶体：XOUT 串 22Ω、XIN/XOUT 间 510K、4Pin 晶体 2 个 GND 脚入地、CL≤12pF
- 复位：nPOR 由 PMIC 控制；RESET_L 100nF
- PMIC：输入 TVS 必贴；BUCK FB 分压随 DDR 类型；控制 IO 属 1.8V（SoC 侧须 1.8V 域）
- DDR：ZQ=240R 1% 接 VDDQ（非地）
- eMMC：IO 仅 1.8V；CMD 上拉 10K
- USB：REXT 200R 不可改；VBUSDET 必须连接
- 网口：MDIO 上拉 1.8K；RSET 2.49K 1%；Bob-Smith 75R+1nF/2kV
```

新项目：以该平台最新官方 checklist 为准重建此节，逐条核对并在报告中给 ✓/✗ 证据。

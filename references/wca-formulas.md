# 参数与边界条件验算（WCA，工程计算与保证值核对共用）

> 读者：审查员。

使用当前装配版本的实际元件值；保证值核对（E）使用其约定要求的有出处保证参数。
阻值字段按 `阻值[/公差][/额定功率][/额定电压][/封装]` 读（如 `1k5/1%/1W`、`1M/1%/250V`、`47R/1%/2W/R2512`）：带完整 `R0402` 等受支持封装后缀时保留数值和显式公差，封装数字不参与阻值；额定功率（W、mW）与额定电压（V）各至多一个，记为 `power_w`、`voltage_v`；未知/冲突后缀拒绝，缺公差不由封装推定。读不出的阻值进计划诊断 `RESISTOR_VALUE_UNREAD`（写原值），计划命令打印出来；末尾单独一段的字母词（`/pulse`，不贴标记 DNP/DNI/DNF 除外）不挡阻值，阻值照读，原值进诊断 `RESISTOR_VALUE_WORD`（BOM 那一行已在料号、封装、位置、数量以外的列写了规格的不列，由审查员按 BOM 原文核）。解析成功也不证明封装功率、耐压、TCR 或全温保证。
工程计算（C）的局部参数、典型曲线和外推按下文[器件参数定界口径](#器件参数定界口径)
核模型、误差及边界方向，足以支持判据时可形成 B 级结论；不将估算值填作 E 所需的保证值。
E96 表示阻值系列，不能证明精度。未知公差、温度系数、Vref 极限或负载不是零；
会改变判断的输入缺口保持 INSUFFICIENT。已证实的保证条件违反为 FAIL，宽松保守上界越限不直接证明实际超限；
PCB 寄生、散热实现和样品测试另建 HANDOFF。

变换器的输出能力与元件电流应力分别结论。用输入功率或限流边界证明目标输出
不能保证，关闭的是能力判据；不能把“为达到该目标所需的电流”当作已实际流过
电感/开关的电流，直接迁移为应力 FAIL。应力项须另给实际可达状态下的峰值/RMS、
限流响应及相应 Isat/温升额定。保护使电流受限、但磁件保证数据不足时保留该应力项
INSUFFICIENT，同时保留已证实的能力 FAIL；重复引用同一计算不合并这两个判据。

## 计算前的模型检查

记录对象、状态、目标量、端点、所有支路、数据来源和忽略项的量化依据。
不同地网不能直接合并；DNP 按装配版本移除。内部拉阻、输入偏置、LED、钳位、
开关以及电容在采样时段的充放电必须建模或证明可忽略。

两电阻分压与反馈分压的窗口按下表公式取全部角点，`calc.py circuit_bounds.divider_bounds` 复算；归并不成串并联的
电阻网络写明所建的线性模型（源网、参考网、每个忽略节点的理由、偏置电流保证范围）再算，
0Ω、读不出的电阻、未建模输入、非线性或多源网络保持 INSUFFICIENT，不截断或抽样。
非零地偏差、源供电余量、启动和环路稳定性仍需独立证据或经核实的仿真，不能由此放行。

## 公式与验收依据

| 对象 | 计算 | 验收条件与限制 |
|---|---|---|
| 闭环 FB 设定值 | Vout−Vground = Vref(1+Rtop/Rbot)+Ibias·Rtop；Ibias 正号流入 IC | 用 R、Vref、Ibias 极限组合求窗口；与每个负载推荐工作范围比较，不用固定 1–2% 误差。结果不证明供电余量或环路稳定 |
| UVLO/OVLO/监控 | 按具体器件阈值、迟滞及分压公式 | 下降沿/上升沿分别计算，比较被保护对象的工作边界、动作延迟和正常电源变化；先确认检测目的及位置 |
| 有钳位的分压 | 源阻抗和器件 I–V 曲线联立 | Vpin 不能直接取 min(未钳位电压,Vz)；核对测试电流、低流拐点、泄漏、温度、限流电阻功率及输入注入额定 |
| strap / 数字输入 | 在 setup/hold 或有效时段求 Vpin_min/max | high 要 Vmin≥VIH(min)，low 要 Vmax≤VIL(max)；窗口越界表示未满足保证条件，不能推导每颗都会失败，也不能以典型翻转点免除问题 |
| 单极 RC、阶跃源 | V(t)=Vfinal+(Vinitial−Vfinal)exp(−t/(Rth·C))；t_cross=−Rth·C·ln((Vthreshold−Vfinal)/(Vinitial−Vfinal)) | 仅限源稳定且单极线性模型。检查阈值可达及对数定义域；源缓升/掉电残压/内部拉阻/泄漏和门限公差另计。τ 不是复位脉宽 |
| I2C 上拉 | Rp_min=(Vpullup_max−VOL_max)/IOL_guaranteed；Rp_max=tr_max/(0.8473·Cb_max) | 按实际速度与每个电气段，所有并联上拉的公差窗口应在两限之间；计入外接板上拉、缓冲器、串阻压降。阻值满足不代表 VIH/VIL、Ioff 或地址已通过 |
| MOSFET 双向开漏电平转换 | 见下文“MOSFET 双向开漏电平转换”小节 | 灌电流、VGS 三档、两侧上升时间、单侧掉电与规则归属分别核对 |
| Buck，理想 CCM 初算 | D≈Vout/Vin；ΔIL≈(Vin−Vout)D/(L·fs)；Ipk≈Iout+ΔIL/2；IL_rms≈sqrt(Iout²+ΔIL²/12) | 按实际拓扑与损耗修正；电感 Isat 定义和温度降额、开关限流 min/max、最小 on/off 时间均核对，禁止推广到所有变换器 |
| Boost，理想 CCM 初算 | D≈1−Vin·η/Vout；IL_avg≈Iout/(1−D)；ΔIL≈Vin·D/(L·fs)；Ipk≈IL_avg+ΔIL/2；在 Vin_min、Iout_max 取最坏 | 异步 Boost 的输出经电感/二极管与输入直通，上电冲击和输出短路电流不受开关限流控制，另按源能力、二极管浪涌额定与需求核；最小 on/off 时间、二极管/同步管应力另核 |
| 电感饱和与开关限流 | 正常最坏点 Isat≥Ipk_max；需求内的启动、过载、短路会进入开关限流时 Isat≥ILIM_max | Buck、Boost 等开关变换器通用。Isat 按资料定义（感量下降比例、温度）取最坏值；若允许限流时短时饱和，须有器件资料证明限流响应能在饱和电流下保护开关；温升电流另核 |
| 随输出变化的线性供电（辅助绕组跟随器、LDO） | P=(Vaux(Vout)−Vcc)·Icc，在输出全范围扫描 | 极值通常在两路供电的交接点，不在端点；输出损耗边界及允许温度约束，实际热路径、结温与闭壳温升移交下游 |
| LDO | P≈(Vin−Vout)·Iout+Vin·Iq | 高温/满载保证 dropout、Cout 有效值/ESR/稳定性、反向电流和放电条件逐项核对；PCB 热阻未知不宣称结温通过 |
| 输入接入过冲（外部源热插拔） | 硬电压源（台架电源、适配器）经引线电感 L 接入 Cin：无阻尼上界 2·Vsrc；串联阻尼 R 时 ζ=(R/2)·√(Cin/L)，ζ<1 峰值≈Vsrc·(1+exp(−πζ/√(1−ζ²)))，ζ≥1 无过冲。限流源（太阳能板、恒流/限流电源）：仅当 Cin 远大于源侧电容（组件/电源输出电容与引线电容之和 Cp）时，ΔV≤Isc·√(L/Cin)，峰值≤Voc+ΔV；Cin 与 Cp 可比或 Cp 未知时，源侧电容经引线向 Cin 放电，峰值上界约 max(Voc, 2·Voc·Cp/(Cp+Cin))+ΔV，按此或硬源模型估算，或做仿真 | 先按需求确定源类型：需求只给太阳能板时用限流源模型，台架电源等可预见的硬源另列一个状态；不能不分源类型一律取 2·Vsrc。Cin 取同一网上全部电容（含电解）的有效最小值；阻尼 R 只能用有保证下界的 ESR/串阻，资料只给 tanδ/ESR 上限时不计阻尼；L 无资料时按引线长度与回路写明假设。峰值对绝对最大额定，稳态对推荐工作范围；原厂对高输入电压给了 RC/限流电路时，列为条件方案 |
| MOS 保护/热插拔 | 导通 I²Rds(on)；线性态瞬时功耗 VDS·ID，能量积分 ∫VDS·ID dt | 依据相应 VDS、ID、脉宽和起始温度的 SOA 检查，不用额定电流或总能量代替 SOA；计时、重试和熔断器配合独立核对 |
| TVS | VRWM 对正常峰值；VBR 对规定 IT；VC 对规定 Ipp/波形 | 再看漏电、温度、脉冲宽度、源阻抗/可用能量和后级承受能力。VRWM 不是击穿电压；型号数字仅用于检索 |
| ADC / 运放 | 分压、偏置/失调/增益误差、RC 建立误差；简单模型误差约 ΔV·exp(−tacq/((Rsource+Ron)·Csample)) | 具体采样结构按 datasheet；同时检查共模范围、输出摆幅、GBW/压摆率、容性负载稳定性和参考驱动；不能只检查 ADC 直流满量程 |
| 晶体 | CL_eff=C1·C2/(C1+C2)+Cstray | 准确晶体 CL/ESR/驱动等级、振荡器适配和起振条件；Cstray 没有通用默认值，布局寄生/起振裕量转 HANDOFF |
| MLCC | Ceff=准确料号的偏压/温度/老化/公差修正 | 用厂家曲线和定义，不填通用 40–70%；有效最小/最大值与器件稳定及储能条件比较 |
| 信号串联电阻（USB/高速数字线串阻） | 直流两端压差只来自上下拉/终端电流时按 I²R；动态部分 P≤½·C·ΔV²·N_tr·R/(R+Rdrv_min)。N_tr 取该接口协议允许的最大跳变率（NRZ/NRZI 取比特率）；C 为驱动端与接收端 Cin、连接器及线缆总电容（传输线取单程时延/最小特性阻抗）之和；Rdrv_min 为驱动端内阻下限，资料未给取 0 | 每项取值引用器件手册或接口标准，取不到的项列为具体缺口；不用 V²/R 的跨轨直流模型，也不以“原厂推荐阻值”代替应力计算。所得上界与 commodity-floors 判定表同一门限比较（≤ 最弱档 50%；超过 25% 时附“额定 ≥ 2×应力”的采购约束），不另加脉冲曲线要求 |
| 电阻/连接器 | P=U²/R 或 I²R；额定工作电压、脉冲、温度降额 | 每颗电阻和每组触点分别检查；并针电流须有制造商组合额定或分流最坏模型，不能机械乘针数 |
| 供电窗口 | 将电源含全角窗口与每个负载推荐工作范围相交；绝限另查 | 未超 Abs Max 不能当作工作正常；轨名只是标称意图 |
| 限流/断路 | Itrip(min)=Vth(min)/Rs(max)，max 反向；分别算快断、恒流、功率限制、TIMER | 最大连续电流额定值不等于电流触发阈值；软件检测不自动满足硬件保护要求 |
| 电流/功率预算 | 各状态下负载峰值、效率、同时工作系数和上游能力；Ipeak≈Iout+ΔIL/2 | 裕量依据需求/策略；Isat 与温升电流分别核，不能只比平均值 |
| 电阻/泄放 | P=V²/R、I²R，电阻工作电压；放电 t=RC ln(Vstart/Vsafe) | 改 24V 泄放电阻同时算满压常态功耗和温度降额；不得仅按放电速度给封装 |
| 跨域/掉电 | 分别核接收端门限、允许输入/注入电流、Ioff、VDD=0 条件、转换器供电顺序 | 不固定接“较高域”或“较低域”；没有直接兼容窗口时用合适转换器/隔离器 |

### 电位器的活动轨段与滑臂

先记录物理端子与滑臂、是否将滑臂短接一端，以及实际分压或两端 rheostat 接法。
整轨额定功率不能直接作为任意局部轨段的允许功率。均匀轨段模型中，令整轨电阻为
Rtotal、按温度/项目降额后的整轨允许功率为 Pallow，活动段电阻为 r>0，则
Psegment,allow=Pallow·r/Rtotal；Itrack,allow=sqrt(Pallow/Rtotal)。活动段实际耗散为 Itrack²·r，
应与本段限值比较。非均匀轨道或厂家另有额定方法时按实际型号条款，不能默认此模型适用。

串联限流电阻 Rs 与理想活动段 r 承受电压 V 时，I=V/(Rs+r)，Psegment=V²·r/(Rs+r)²；
Rs>0 时功耗极值可能在 r=Rs，电流极值趋近最小活动电阻处，不能只核最大阻值或最大总功耗。
近零/端点、接触电阻、滑臂电流及脉冲/重复率另核；滑臂短接一端不自动证明滑臂被旁路，
须按接触与剩余轨段的实际并联路径定界。上述轨段公式不证明端点或滑臂安全。
没有实际器件或适用轨道/滑臂保证时保留具体缺口；候选系列和未定外接电位器不借用普通电阻最弱档。

方法依据：[Bourns Potentiometer Handbook，印刷 p.66 “Power Rating as a Rheostat”](https://www.bourns.com/docs/technical-documents/technical-library/corporate/OnlinePotentiometerHandbook.pdf)。
该方法不把手册示例的电流上限或某候选功率推广为所有电位器的额定。

### MOSFET 双向开漏电平转换

结构：单颗 N 沟道 MOSFET，栅极接低侧轨 VL，源极接低侧信号（上拉 RL 到 VL），漏极接高侧信号（上拉 RH 到 VH）。
集成转换器（TXS/TXB/LSF 等）不套用本节，按其手册的内部上拉、单稳加速、外接上下拉、容性负载、OE 与 Ioff 条款核对。

| 项目 | 计算 | 验收与归属 |
|---|---|---|
| 灌电流 | 任一侧拉低到 VOL 时，驱动端吸收 I = (VL−VOL)/RL + (VH−VOL)/RH；对侧电流经沟道的 I·RDS 压降忽略时偏保守 | 电阻取最小值、电源取最大值，I ≤ 驱动端保证 IOL；I²C 上的转换器同样按两侧之和，不能只算本侧 Rp_min。归 SIG-C07（I²C 上同时满足 SIG-C01） |
| 对侧低电平 | 对侧 ≈ VOL + I_对侧·RDS(on)；两个驱动方向分别算，高侧驱动时低侧节点 ≈ VOL_H + I_L·RDS | ≤ 对侧接收端 VIL(max)。归 SIG-C07 |
| 导通保证（VGS 三档） | VGS = VL_min − VOL_max（高侧驱动时 VOL 取高侧驱动值加沟道压降）。此处取 VL 最小值、灌电流取 VL 最大值，是有意的保守组合 | ① 低于 VGS(th)max：导通无保证，判保证要求未满足；② 介于 VGS(th)max 与 RDS(on) 测试 VGS 之间：RDS 无直接保证，用覆盖该工作点（VGS、ID、温度）的曲线或模型定界，判 B 级，无法定界则 INSUFFICIENT；③ 达到测试 VGS：使用保证 RDS(on)，并核其测试电流和温度条件。归 SIG-C07 |
| 上升时间 | 驱动端释放后沟道仍导通，两侧先一起由 RL∥RH 对 CL+CH 充电；低侧升到约 VL−VGS(th) 后沟道截止，两侧再各由本侧上拉对本侧电容充电。单段近似 t = R·C·ln((Vmin−V起)/(Vmin−V止))，R 取最大值，C 含 MOSFET 端电容；简化计算时两段都取较大的时间常数（偏保守） | 需求未定义测量点时，按接收端门限从 VIL(max) 到 VIH(min) 判定：该口径直接对应接收端能否识别电平，不因 10%–90% 等其他口径会得出不同结论而转需求澄清。需求写明口径（如“VDD 的 10%–90%”，VDD 未注明时取实际电源最小值）或引用了规范时从其定义（I²C 为 30%–70%，即 0.8473·Rp·Cb）；引用的规范本身也没有定义时才转需求澄清。归 SIG-C09（I²C 上归 SIG-C01） |
| 单侧掉电 | 上电侧经上拉 → 体二极管/反向导通的沟道（掉电侧漏极接近 0 V 时 VGD 可超过 VGS(th)）→ 掉电侧。上电侧空闲电平：仅体二极管导通时 ≈ VF + (VL−VF)·RH/(RL+RH)；沟道全通时 ≈ VL·RH/(RL+RH)。流入掉电轨的电流 ≈ (VL−VF)/(RL+RH)（沟道全通时约 VL/(RL+RH)）；掉电器件引脚有钳位时，注入钳位最坏约 VL_max/RL_min | 证明 FAIL：取上述两式中较高者并用有利角点（VF 取上限），仍低于 VIH(min)。证明 PASS：取两式中较低者并用不利角点（沟道全通、VF 取下限），仍高于 VIH(min)；只核体二极管不足以证明 PASS。注入 ≤ 掉电器件的注入/Ioff 限值；另核掉电轨在轻载时是否被注入电流抬升而反向供电。归 SIG-C08 |
| 管子方向 | 源极（体二极管阳极）须在低侧 | 接反时低侧信号经体二极管被高侧钳制。归 SIG-T04；I²C 上并入 SIG-C07 |

SIG-C08 判 NA 的依据须是“两侧在需求覆盖的全部状态下同时上电、同时掉电”。两侧来自同一电源但为不同派生轨、
上电先后或斜率不同时，不能据“同源”判 NA，仍按上电/掉电过程核注入与误动作。

## 必查状态与留档

在每个具体电路上判断适用性：冷启动、慢爬升、棕断、短暂掉电、单域掉电、
外部接口先上电、热插拔、满载/空载、短路、负载瞬态、温度极限和装配变体。
缺失需求要列为待补证据，不擅自填写最坏工况。对每项记录公式、位号/网络、数据与
文档定位、角点、结果范围、判据、审查意见和复验方法。

## 修改建议的复算

对每项建议写“旧值/旧网→新值/新网”、假设、修改后全角计算、关联器件、装配状态和通过标准。
未掌握输入/负载/保护窗口时不给唯一确定阻值或替代料。禁止用“软件强制某模式”替代硬件保护，
除非需求允许且启动/掉电/故障场景均有依据；不能自动豁免明确必需的功能。
只由 PCB/实测决定的寄生、真实温升、SI/EMC 列 HANDOFF，仍完成原理图可算的应力与损耗。

LDO 的反馈设定值须比较 Vin 与保证 dropout；计算设定高于输入不代表器件能升压。
ADC 的 FSR 是转换量程，模拟脚的绝限和共模窗口仍须独立核对。

## 保护动作窗口与裕量

审查保护动态或据此阻断冻结时，按“后果 → 允许窗口 → 实际响应/裕量 → 关闭阶段”记录，可共用有定位的分析表，
不要求每颗器件重复一套证明。温度范围来自产品环境、内部温升与所选器件工作条件；环境温度不能直接当结温，
也不能把器件整个额定温区自动变成新增产品测试矩阵。

1. 明确故障起点、供能路径、受保护对象和可接受终态。区分正常关断、协议放电、过温、过压/反馈失效和短路；
   同一个功率管的不同功能不能共用一个无依据的“必须足够快”。允许的永久安全失效也按需求保留。
2. 从适用协议/需求或损伤机理求允许窗口：例如受控充电电流与电容产生的电压上升、限流能量与SOA、热惯性，
   并计入独立限能/钳位。没有单一时间阈值时可用电压/能量轨迹约束；不强造微秒指标，不把端口放电时限当OVP响应时限。
   窗口尚不能算出时写明缺哪个源界限/器件耐受、可能后果和计算路径。由工程核定的窗口不转成用户待决指标。
3. 对同一起终点比较检测、逻辑/隔离、执行和必要放电时间，避免漏段、重复计时，或把特定负载的芯片延迟当整链时间。
   使用适用厂家限值或有依据的工程界限；裕量须覆盖实际变化与模型误差。典型值乘任意倍数、仅凭数量级不同、
   未知限值与未知响应相减，均不能证明保护成立。反之，充分的设计证据不必逐参数补齐全温最大表或整链实测。
4. 原理图的路径、门限、额定、控制能力及裕量已经成立，剩余是PCB寄生、实物波形、热分布和模型相关性确认时，
   将已成立子判据判PASS（注明范围/证据等级），试验写成具体HANDOFF。仅有模型假设且关键界限决定保护是否有效时，
   仍为设计/证据阻断；不能通过更名“样机验证”放行。缺确切时间数值但已有独立限能保证时，不再强求该时间来证明同一后果。
5. 检查方式保持一致：连通追踪只核本条路径，正常状态只核该状态；动态协同在相应故障项审查。不得把同一动态缺口
   复制到器件选型、去耦、正常使能及每个电路检查项上。原条判据确含多个要求时拆清结论，不能删掉适用的要求。

### 故障停能与器件耐受的同一时间轴

1. **分段记时间轴**：故障发生 → 检测量到门限 → 滤波/消隐结束 → 驱动停止 → 最后储能释放，各段分别定界。
   芯片检测延迟只从其规定的引脚条件起算，不含前级跟随；停止送能不等于输出已放电或端口已断开。
2. **只组约定时可达的值**：正常最大值、保护异常上界、寄生预算各标来源；只有时间上相容的组合才算实际故障包络。
   反馈失效按准确订货后缀核限流、频率钳位与过载计时，不借用其他后缀的保护。探索组合只用于找决定性输入。
3. **能量不漏不重**：每次送能上界 L·Ipk²/2（CCM 按此为保守上界），另计时间起点已有的储能和最后一包。
   短故障按有限时间积分和真实重试节奏核脉冲能力，周期平均功率不能证明短时安全，"只有几微秒"也不能免除脉冲额定；
   连续工作另核连续额定与散热。计算可用 `scripts/calc.py fault_energy.*`。
4. **用已有保证构造充分上界**：单调关系可直接用测试点保证值定界（如固定温度、规定测试电流下的齐纳最大 VZ），
   不为此强求全部低电流曲线；反方向的下界、温漂和动态跟随仍另核。
5. **未约束的参数反算范围**：辅助绕组耦合、有效容量等若影响余量，反算允许范围并提出受控规格或替代方案，
   不伪造保证；原理图未定的范围是设计缺口，PCB 寄生与样机相关性另作具体移交。

建议分析记录：`scenario`、`consequence`、`allowed_window`、`response_bound`、`margin`、`temperature_scope`、
`closure_stage`及证据定位。窗口/响应可明确写UNKNOWN或NOT_TIME_LIMITED及原因；无需为了填表造数。
机器`quality_screening`对缺窗口的动态阻断只给复核提示，不自行判PASS/FAIL或降低等级。

### 齐纳检测、停能与锁定供电

阈值检测按三个判据分别核，同一未知不复制到三处：

- **不误动作**：正常工况下流入接收脚的电流低于最小触发所需（`calc.py zener_fault.no_trip_budget`）。
  最坏静态电压短暂越限时，可用有界波形和滤波/消隐证明不形成有效触发。
- **动作有效**：用测试点保证上限构造充分供流条件（`zener_fault.trip_drive`）；充分条件不是实际动作点或全温保证。
  齐纳标称电压只属于其测试电流/温度，偏离测试电流时按下文“齐纳管低电流”定界。
  储能电容节点不能按匝比当作瞬时输出；峰值捕获、充电跟随、滤波、判定和执行分别定界，所需范围从判据反算。
- **保持与复位**：锁存器只证明逻辑。保持依赖供电时，核锁定期间的实际供源、全部并联负载（未证明另一保护
  已关闭就不能删去其负载）、供电缺口、有效电容和复位电压（`zener_fault.hold_charge`）。各种复位途径分别记录，
  手册典型复位方式不能代替本电路的供电核算。

检测电流不是限流值：故障继续上升或停能后的残压仍会让齐纳、串阻和引脚受流，按实际电压与持续时间核热或脉冲能力。
正常工作与允许破坏性故障的验收边界分别引用需求。

## 器件参数定界口径

先用已有资料完成适用模型下的计算和定界。采用局部参数、典型曲线或外推时，记录模型适用的
电流/电压、温度、工作区与拓扑范围、不利方向，以及误差和裕量依据；不能仅因加了余量就称为保守边界。
足以支持本条判据的工程推导可形成 B 级结论；缺口不影响结论时无需追加补证，也不强求每个工作点都有独立保证值。

- **齐纳管低电流**：核实际电流范围是否仍在所用模型的稳压区。单一测试电流下的 rdif 是局部参数，
  不能直接作为跨入低流拐点后的全区间斜率；工作电流落在两个 rdif 测试点之间时，取较低一端的 rdif 保证上限作斜率上界，VZ ≥ VZmin(IZT) − rdif_max(I₁)·(IZT − I)，记 ADJACENT_TEST_POINT（2026-10-23 定）；用覆盖该区间的曲线、分段模型或有依据的斜率界限，计入温度与自热。
  只有局部数据时可先估算，但“拐点余量”须有来源或误差依据。最低测试电流以下又没有覆盖工作点的曲线，是用在手册未规定的区间：记失败项（改法是把电流提到测试点以上），不向厂家索取（2026-10-26 定）。
- **MOS 实际电流下的 VGS**：优先用实际电流、VDS、温度下的传输曲线或适用模型，并计入阈值与器件分散。
  原厂允许的阈值偏移法可用于工程推导，但须保留其假设；单点 gfs 不是从阈值到目标电流的全程常数，
  不能直接把 VGS(th) 上限加单点斜率外推当作保证边界。开关的 RDS(on) 保证条件仍独立核对。
- **吸收电阻功耗**：CV²f 用于每周期经电阻充、放电的简单 RC 估算，先核电压摆幅及充放电是否充分，
  并满足该模型的时间尺度条件（电压上升时间远小于 RC，RC 远小于有效充放电时长）。
  仅放电经电阻的相应 RCD 模型为 ½CV²f；钳位型按漏感能量、钳位电压及实际路径另算，不能统一套用。

- **二极管反向漏电**：25 ℃ 的 IR 最大值不是高温上界。按实际反压和最高结温读温度曲线；曲线是典型值时，
  用同一测试点“保证最大/典型”的比值外推并标为估计，不能用 25 ℃ 最大值代表全温。
- **外部输入接入过冲**：先按需求确定源类型再选模型（见上文[公式与验收依据](#公式与验收依据)“输入接入过冲”行）。
  只用硬电压源的 2·Vsrc 上界判“无法定界”是没有收紧边界；限流源模型只在输入电容远大于源侧电容时成立，在适用模型或有保证阻尼下仍超限才保留缺口。

- **保证条件与实际条件不同（单调外推）**：手册只在某一条件下给出保证值（如 VDD=2.5 V、25 ℃ 的 VOH/VOL，
  某电流下的压差），而手册自己的典型曲线显示该参数随条件单调变化、实际条件处在更有利的一侧时（更高的 CMOS 驱动电压、
  更小的负载电流、更低的温度下的漏电），可直接把较差条件下的保证值用于实际条件，结论为 B。
  曲线不单调、或实际条件在更不利一侧时，不能外推。
- **只有典型值的参数**：能不能用典型值估算判 PASS、打几倍折、什么后果类能用，以定界表那一格的[判决边界](bounding-table.md#判决边界)为准（2026-10-26，边界按器件类型）；
  下面是通用口径。手册对该参数完全没有给出 min/max 时，按以下顺序取离散范围，写明出处：
  ① 同一手册中同类参数的 min/max 相对典型值的比例；② 同系列或前代器件对同一参数的保证范围（相似器件参考）；
  ③ 都没有时按典型值 ± 降额规范 `typical_band` 计。结论在整个范围内都不变，才可判 PASS，并把“样机实测该参数”记为必需移交。
  方式②③是估算范围，不是本器件的保证值：可用于必需功能、性能和指示类判据（含 P1），P1 采用时整个范围内结论不变，并把“样机实测该参数”记为必需移交（余量记 ESTIMATE，写 `consequence_class` 和 `handoff`，见 [结果格式](results-format.md)）；
  这样判出的 PASS 是 C 级证据、“合格，但有风险”（不是 B），余量写 `risk`（风险类型取定界表那一格的“估算对应的风险”，写只靠估算的角点和改法）；
  可能造成器件损坏、过热、安全危害或保护失效的判据，仍须有本器件保证值，没有时按公开资料界限判断（见[判“证据不足”之前先定界](evidence-proportionality.md#判证据不足之前先定界)第 4 步与定界表推法）。
  手册按工作模式列出功耗/电流（只有典型值或典型与最大混列）时，负载上界取所列最重模式的最大值（只有典型值时取典型 ×1.3），
  需求声明了超出手册所列模式的工作负载（超频、手册未列的外设组合）时才另算；不要求设计方给逐模式预算，
  “软件最高时钟/外设组合未定”不是缺口。同样不用于器件损坏、过热和保护判据。
- **原厂典型应用等效**：电路与原厂手册或应用笔记中的典型应用一致（拓扑相同，器件值在原厂给出的范围内，
  输入与负载在原厂声明的条件内）时，该应用所决定的性能（稳压器稳定性、补偿、启动、内部基准配合外部分压）
  按原厂设计判定，结论为 B，引用原厂图号；器件应力、绝对最大额定和超出原厂条件的部分仍按本表计算。
  仅有典型应用等效的路径同样只用于必需功能和性能（P1 时另记样机验证移交）；器件损坏与保护保证须有适用保证或明确的原厂条款。
  原厂明确不要求输出电容维持稳定且实际满足其条件时，可对本体稳定性作窄 PASS；电容额定、反向能量等独立判据仍核。
- **脉冲与浪涌**：脉冲峰值功率不超过器件连续额定，峰值电压不超过最高工作电压时，不需要脉冲曲线即可判 PASS；
  超出才按同波形、脉宽、重复率的脉冲额定比较。
- **检流电阻**：料号未定时，按所在系列（或 BOM 写明的精度档）最差公差与 TCR 乘以实际温升，求阻值上下界；
  量程、限流点等判据在上下界内都成立就判 PASS（B）。只有电路声明测量精度、且精度预算依赖具体料号时，才要求确切料号。
- **物理上限定界**：未知参数受电路物理约束时，直接用约束值定界，不需要该参数的全温最大值：
  节点电压不超过所接供电轨、钳位/齐纳的保证最大值或驱动器供电；电流不超过上游限流电阻、源的保证限流或保险额定；
  功耗不超过源能提供的最大功率。用这类上界算出的应力在额定内即判 PASS（B），可用于 P1 判据。
  这不是借用相似器件或典型值估算，也不是“典型值乘任意倍数”；约束本身须有保证值或已 PASS 的检查支撑，
  并写明引用的那条检查 ID。约束器件自身的动态/温度条件在约束器件的检查里审，不复制到每颗被约束器件上。
- **已有包络的通用件**：计算已给出两端电压/电流包络（如“2.048 V 基准 ±1.1% → 2.071 V”）且在最弱档或可订购档内，
  DEV-C01/PWR-C10 判 PASS（B），不因“源的动态条件尚在其他检查”而保留证据不足；源的缺口只留在源自己的检查里。

定出的界怎么判（PASS、FAIL、INSUFFICIENT 与“保证要求未满足”）见[余量判定规则](margin-verdicts.md)。

## 功率开关：实际栅压、关联损耗和 SOA

确认开关在实际驱动下能承载要求的电流、转换与重复能量可承受；漏查可能导致功率不足、过热或转换时损坏。
复用偏置、电流包络和保护状态，不为同一未知重复建整改任务。

- **栅压落到物理参考点**：分清驱动器电源、对地输出和 MOS 的 VGS；源极采样电阻压降按同一电流扣除，
  稳态栅阻只流栅极/下拉电流。UVLO 只证明何时停驱动，不证明导通期间 VGS 下限。
- **测试 VGS 不是通过门槛**：VGS 低于 RDS(on) 测试条件时，先用本型号曲线核实际电流和温度下的能力；
  只有不确定性跨越必要工作或额定边界才保留缺口，换件是现有范围无法满足时的方案。
- **损耗参数须同时发生**：按控制器模式配对 Vin、母线、负载、频率、死区和温度（`calc.py boost_switch_loss.*`）；
  导通、转换、残余 Coss、二极管能量分列，使用已含 Coss 的 Eon/Eoff 时不重复计入。超出控制器脉宽/限流的组合只用于反算。
- **正常与故障分开**：故障峰流 × 最高母线 × 任意持续频率不是正常损耗；故障按限流和停能/重试的时间轴核，
  单脉冲按时间与起始温度，重复过程按热模型。单脉冲 SOA 不能证明重复开关，低 VDS 导通时间不等于高压重叠时间。
- **算到足以决定为止**：典型值只作量级估算并标明；由损耗反算允许壳温/散热或转换时间，纯 PCB 实现与实测走 HANDOFF。

## 假设、上界与实际故障的证据门槛

会改变结论、严重度或换件建议的数值，就近记录来源、适用工况、推导和性质：已确认事实/保证、有依据的上界、
待实现的设计约束、探索值、未知。

1. **不凭未知造数**：探索值只能用来找敏感因素或反算所需范围，不进入实际应力结论或严重度依据；
   缺关键输入写"未能定界"，不默认 0、不放大到任意值、不拿器件额定值充当钳位值。
2. **上界有方向**：模型覆盖实际可达状态且不利方向有据才算上界。上界满足判据可支持通过；
   上界越限只说明需要收紧，确认超限需要确会出现的工况或足以证明违反的边界。
3. **同一时刻、同一状态**：不同开关阶段的极值相加只能做保守筛查，越限不证明同时发生。
   例：反激同步整流管 `Vout+Vbus/n` 只对应初级导通段（`calc.py flyback_stop.primary_on_sr_platform`），
   不能与停机后的最高输出组合。
   **一次只取一个瞬态或故障事件**（2026-10-27）：叠在持续最坏工况上，两个独立的稀有事件不同时取；物理上同时发生的照叠
   （浪涌叠电网峰值、脉冲额定按起始温度降额）。结论比瞬态额定（瞬态降额值只定应力风险），持续比持续额定；内部节点只取能到达它的瞬态。
4. **预算不是验证结果**：尖峰预算由器件限值减去同状态平台导出，仍须由有效模型、适用参考设计或受控参数证明可达成；
   RC 吸收是阻尼不是钳位，`C·V²·f` 不能反证代入的尖峰，不能循环引用同一预算。
5. **核公式覆盖范围**：停能后电容电压 `sqrt(Vstop²+2E/Cmin)`（`flyback_stop.post_stop_capacitor_bound`）要求
   计入全部剩余能量并排除重启/反灌；忽略负载可保守，忽略储能不保守；不含 ESR/ESL 尖峰。
6. **说给人听**：先说哪个器件、什么状态、防什么，再给已确认事实和未闭合范围；电压标明参考点，精度匹配证据。
   撤回无依据场景后按剩余必需判据重定级，不自动转 P1 或 PASS。

# L4 参数与边界条件验算（WCA）公式库

> **分压类先用脚本**：`python3 scripts/solve_dividers.py db.json --vfb <REF>=<VFB>`。
> 它沿电阻串递归求和，正确处理任意长度的串联上/下臂——这是分压算错的首要原因，
> 且无法靠肉眼规避（实测某板 15 处分压全部含串联臂）。本文公式用于理解与手工复核。

代入网表**实际阻容值**（E96 实值，含公差）验算，不采信标称意图。每个关键电路必须过边界条件清单。

## 公式表

| 电路 | 公式/规则 | 验收标准 |
|---|---|---|
| 可调电源 FB 分压 | Vout = Vref × (1 + Rtop/Rbot) | 与目标电压误差 <1-2%（E96 实际值）；**负载器件推荐工作条件 min/max 必须覆盖公差窗口**（实例：算出 0.906V 但下游芯片下限 0.93V → 欠压） |
| UVLO/OVLO 门限 | Vth_in = Vth_pin × (1+Rtop/Rbot)，含迟滞 | 门限窗口落在设计"无人区"，公差叠加后仍有裕量 |
| 电压监控动作点 | VTHx = Vth_pin × (R1+R2)/R2（R1=上臂，R2=下臂**串联求和**） | 动作点 vs 注释意图、vs 被保护器件工作下限；给 typ+min/max（实例：0.62×(100+3.49)/3.49=18.39V vs 注释 20V） |
| 限流/恒流 | 按器件公式（如 IOL=18/R、K_CL/R） | 限流点与系统保护线之间留裕量；两路同器件限流值不一致需解释 |
| 软启动 | 按器件公式（如 t=k×VIN×C） | 浪涌 I=C·dV/dt 低于源端限制 |
| 稳压管钳位 | 脚压=min(分压值, Vz) | 宽输入范围下端高于检测门限、上端低于引脚耐压；**低流拐点（knee）要计入**（实例：13.6V 档 Iz 仅 106µA 落拐点区，脚压可能低于窗口下限） |
| ADC 检测分压 | Vadc = Vin × R2/(R1+R2) | 满量程不超 ADC 上限；各判定档位间隔 ≫ LSB 与误差之和；运放 buffer 注意共模上限 |
| RC 复位 | τ = RC | 满足器件最小复位脉宽 |
| I2C 上拉 | 总线上拉等效 1-4.7K，电源=总线域电源 | 多器件地址不冲突；上拉电源与 GPIO 域一致 |
| 晶振负载 | CL_eff = C1×C2/(C1+C2) + Cstray(≈3~5pF) | 与晶振料号 CL 匹配；无"典型 CL"臆断，按实际料号 |
| MLCC 直流偏压 | 有效容量 = 标称 × 偏压系数 | 偏压系数取 40-70%（查厂家曲线），不得低于功能需求 |
| 电阻功耗 | P=U²/R、P=I²R | 不超过封装额定（建议 ≤50-70% 降额；>20V 分压每颗算） |
| 开关器件耗散 | P = I² × Rds(on) | 结温裕量；eFuse/负载开关满载核算 |
| 监控/检测电阻跨接 | 误接两轨间的电阻：I=(Va−Vb)/R，P=I²R | 任何新增电阻核对两端各自所在网络（实例：滤波电阻一端误落 24V 一端 12V → 1.2A/14.4W 上电即烧） |

## 边界条件清单（每个关键电路必过）

- 最高/最低输入电压
- 满载/空载
- 启动/热插拔
- 输出短路
- 负载瞬态
- 温度范围（工业级 −40℃ 需求核对器件温度等级）
- 器件公差叠加：电阻 1% + IC 阈值 ±2% + 基准温漂
- 上电时序：EN 链顺序、未上电域被上拉倒灌

## 选型复核

- 对照平台 checklist 的硬性参数（如 Buck 电感 Isat≥X、DCR<Y）
- **封装兼容性**：替换料的封装/端子尺寸与 PCB 焊盘必须一致——电气可换≠物理可焊（实例：201610 ↔ 252012 不可直换）
- 器件身份三要素一致：库符号名 / 封装 / 外围参数（分压比、基准值）互相对得上（实例：库写 SGM2048-ADJ 但封装无 PG 脚、分压比对应基准 0.55V 而非 0.8V → 物料身份存疑）
- 防护/浪涌器件类别 ≥2 个独立证据源（凭库名判断结构会翻车）

## 计算留档要求

报告中所有复算给出：公式、各臂实际阻值（含位号）、代入过程、结果（typ 与范围）、判定基准（datasheet 条款）。可复现是硬性要求。

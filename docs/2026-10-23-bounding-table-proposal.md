# 工作点定界表：把“工作点对手册”的审查固化成规则和公式（方案草稿）

日期：2026-10-23。状态：方案，未实施。整体已确认做（用户在逐项选择中选“做”，属架构调整）；第五节 A–F 全部已定（原话记在各条末尾）。

方向按用户原话：“根据电路知识，把这些工作点的审查方案最好都固化成规则和公式，别让 Agent 自行判断。”

## 起因

资料不足最多、两份审查分歧最大的地方，都是同一类问题：器件在板上的工作点，和手册给保证的测试条件对不上。
例如齐纳管工作在低于测试电流的区间、MOS 的 SOA 只给了 25 °C 壳温、NTC 只给了 B25/50。见
[同一界限一边开项一边通过](2026-10-23-bounding-consistency-proposals.md)。

SR 现在对这类问题有原则，但有三个缺点：
1. **原则分散**：写在 `evidence-proportionality.md`、`wca-formulas.md`、`datasheets.md`、`commodity-floors.md` 和十几条规则的判据里，没有一处能查全。
2. **原则是文字，不是公式**：例如“不利方向上相邻测试点的单调夹出的界限”，哪个参数往哪个方向单调、怎么夹、夹不出时归哪一档，要审查员自己判断。
3. **门禁只核写法**：工作点和测试条件都是自由文字，门禁比不了数。

结果是同一张手册表，审查员 A 判“推不出”开项，B 推出来判通过或判失败。

## 目标：哪些固化，哪些仍由审查员做

| 固化成规则和公式（工具和门禁按表执行） | 仍由审查员做（无法从表里得出） |
|---|---|
| 每类器件每个参数：随什么变、往哪个方向单调 | 从手册抄出测试点的数值，并写页码、表号 |
| 每个参数允许用哪几种推法，按什么顺序 | 用电路计算出本板工作点的范围（可用已有公式库） |
| 每种推法的公式和适用前提 | 决定有哪些工作态（按需求和手册的模式名） |
| 推不出时归四档中的哪一档 | 表里没有的器件类别，按通用推法写，门禁照样核 |
| 门禁按记录的输入重算界限和余量，与审查员写的不符就拒收 | — |

审查员不再决定“能不能推出界”和“推不出时记什么”，只负责抄数和算工作点，这两样门禁都能核对来源。

## 一、表的形状

定界表登记在 `scripts/catalog.py`（与规则同处，按“规则只在 catalog 登记”），每一格：

```
BOUNDS[器件类别][参数] = Bound(
    varies_with,       # 随什么变：电流 / 电压 / 温度 / 脉宽 / 频率
    direction,         # 单调方向：随 x 增大参数 增大 / 减小 / 不单调
    needs,             # 手册须给的测试点：如 “VZ min/max @IZT”“rdif max @ 两个电流”“SZ min/max”
    methods,           # 允许的推法，按顺序：G1…G10 的子集
    formula,           # 每种推法用的公式（calc.py 里的函数名）
    valid_if,          # 适用前提：如 “工作电流在两个 rdif 测试点之间”
    fallback,          # 都推不出时：第三档（缺厂家数据，附典型估算）或第四档（失败项）
    sources)           # 这一格取自哪份参考文档的哪一节
```

参考文档 `references/bounding-table.md` 由 `catalog.py --write-doc` 从这张表生成，与 `check-catalog.md` 同法，不手写。

## 二、通用推法（G1–G10）

这些推法不分器件，表里每格从中挑。每种都有公式，门禁能重算。

| 编号 | 推法 | 公式 | 前提 | 得到的依据 | 现有出处 |
|---|---|---|---|---|---|
| G1 | 保证限值直接覆盖 | P ∈ [min, max] | 工作点在限值的测试条件（`regime`）内 | 保证最坏值 | `evidence-proportionality.md` 第 4 步 |
| G2 | 单调有利侧 | P(x) ≤ Pmax(x₀)（或 ≥ Pmin(x₀)） | P 随 x 单调，工作点在测试点的有利一侧；单调性由典型曲线证明 | 保证最坏值 | 第 4 步，“单调外推”一条，`故障停能` 第 4 点 |
| G3 | 两测试点之间的斜率界 | P(x) ≥ Pmin(x₂) − s_max(x₁)·(x₂ − x)，x ∈ [x₁, x₂] | 斜率随 x 单调变化，取区间内斜率最大一端的保证上限 | 保证最坏值 | 新（第 1-A 条已确认：“1A，可以”） |
| G4 | 温度系数 | P(T) = P(T₀) + S·(T − T₀)，S 取 min 或 max 中不利的一端 | 手册给了温度系数的 min/max | 保证最坏值 | 第 4 步“温度系数的 min/max” |
| G5 | 公开特性表 | 表内插值（NTC 按 ln R 对 1/T 线性），公差取表给的上下限 | 工作点在表的范围内 | 保证最坏值（表给公差时）或估算 | `datasheets.md`“公开曲线表先于索取” |
| G6 | 物理约束 | 节点电压 ≤ 供电轨或钳位保证最大值；电流 ≤ 上游限流 | 约束本身有保证值或已通过的检查 | 保证最坏值 | “物理上限定界”一条 |
| G7 | 同一测试点比例外推 | P_worst(x) = P_typ(x) × P_max(x₀) / P_typ(x₀) | 有典型曲线和同一测试点的保证值 | 估算 | “二极管反向漏电”一条 |
| G8 | 典型曲线覆盖工作点 | 按典型曲线取值，加 G7 的比例 | 典型曲线画到了工作点 | 估算；典型值本身已不够时，按“可达的反例”判失败 | 新（2-A 已确认：“2A，算”） |
| G9 | 只有典型值 | ① 同手册同类参数 min/max 比例；② 同系列保证范围；③ 典型 ±30% | 不用于损坏、过热和保护判据 | 估算 | “只有典型值的参数”一条 |
| G10 | 厂家参考电路同接法 | 接法相同、负载不重于本板 | 引图号 | 可判通过 | 上一份方案第 5 条 5c 第二档 |

推法用完仍推不出时，按表里该格的 `fallback` 落到第三档或第四档，不由审查员挑选。

## 五、要你定的口径

**A. 表的约束力**：表里有的器件类别和参数，审查员必须按表的推法和顺序走，门禁按表重算；表里没有的，按通用推法 G1–G10 写，门禁只核写法。我建议这样定。

**确认（2026-10-23）**：用户选“必须按表”。

**B. MOSFET 高温 SOA**（R5 上 6 行）。手册通常只给 TC = 25 °C 的直流 SOA。
- 恒功率段（对数坐标上斜率 −1 的那段）：按 P(Tc) = P(25)·(Tjmax − Tc)/(Tjmax − 25) 降额，反算允许壳温，写成热设计约束，行可判通过并移交热设计。我建议这一段这样定。
- 高压热不稳定段（曲线比恒功率线更陡的那段）：线性降额不保证安全。可选：
  - ① 记第三档，同时按线性降额给估算；
  - ② 要求工作点留出固定余量（例如不超过该段 25 °C 曲线的 50%）后判通过；
  - ③ 判第四档。
  我建议 ①。

**确认与修订（2026-10-23）**
- 恒功率段：用户原话“这里也可以给出散热结构设计上的要求，交给下游的PCB设计”。所以按公式降额后，除允许壳温外，还写出散热要求交给 PCB 设计：所需壳到环境热阻 Rθca ≤ (Tc_allowed − Ta_max) / P。
- 热不稳定段：用户先答“不超过该段25度曲线的80%就判通过”。我指出高壳温下这段曲线还会缩，用户问“根据你的电路知识和一般的做法，这个地方应当怎么样去设计更恰当？因为这可以说是一个瞬态的过程”。修订后的写法见下文“B 的修订写法”，已确认。

**B 的修订写法**（确认 2026-10-23，用户原话“B 热不稳定段按修订写法定：按持续时间选曲线、按开始壳温降额、降额后留 80%。”）

按工作点持续多久选曲线，再按开始时的壳温降额，最后留余量。

1. **选哪条曲线**
   - **连续工作**（源跟随、线性稳压这类一直工作的点）：用直流（DC）线。
   - **单次瞬态**（启动、热插拔、故障到保护动作）：用不短于实际持续时间的单脉冲线。实际时长落在两条线之间时，取较长的那条。功率按峰值功率保持整个时长计，偏保守，不用等能量换算。
   - **重复瞬态**（打嗝重试、周期性脉冲）：用瞬态热阻曲线 Zth(tp, D) 算结温，Tj = Tc + Ppk·Zth(tp, D) ≤ Tjmax（含项目降额），同时仍核单脉冲线。
2. **温度降额**
   - P_allowed = P_curve(VDS, tp) × (Tjmax − Tc_start) / (Tjmax − 25)。
   - P_curve 在本板 VDS 处从曲线读，热不稳定段已在曲线形状里。
   - Tc_start 取瞬态开始时最高的壳温，例如最高环境温度下稳态运行后再热插拔。热设计没给这个数时，反算允许的 Tc_start，连同散热要求交热设计和 PCB。
3. **余量**
   - 恒功率段：工作点不超过降额后的 100%。
   - 热不稳定段：工作点不超过降额后的 80%。理由是这一段温度越高越不稳定，线性降额对它偏乐观。80% 采用用户给的数，是工程取值，不是厂家保证，报告里照此写明。
4. **超出时**：在本板可达的工况下超出，判失败项，给出改法（换管、降 VDS、缩短时长、加散热）。

## 九、局限

- 表只能覆盖常见器件类别。表外的器件仍靠通用推法，门禁只核写法，这部分的一致性不会提高。
- 工作点本身（板上电流多大、温度多高）仍由审查员计算。算错了，表照样给出错的结论。门禁能核来源，不能核计算模型选得对不对。
- 手册数值抄错由 `audit_parameter_claims.py` 核，前提是审查员写了原表摘录。
- 第五节的几个口径要基于电路知识定，定错会系统性地偏松或偏严。所以每条都要在典型电路基准和 R5 上回放，看过严、过松计数。

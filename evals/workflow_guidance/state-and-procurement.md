# 工况、物理后果与采购边界：合成执行评价

本评价用于复核 G2/G3/G4/G7 的审查方法，不是自动电气判据、真实板级结论或独立盲测。
使用现有 catalog 规则与字段；逐例阅读输入后给出适用判据、结论边界、真实缺口和关闭任务，再与下列期望对照。
不按措辞打分：对象/装配状态、实际因果和可关闭范围全部成立才通过。验证器字段完整或零提示不能给本评价代打分。

| 例 | 合成输入 | 期望边界与关闭动作 |
|---|---|---|
| WG-01 | 接口处于 RUN，双方电源有效；本地电平满足手册；外部地偏移未定。草稿只引用 Ioff/UVLO 并索取关电条件。 | 修正 RUN 的理由/任务；本地已核电平保留，外部共模仍 INSUFFICIENT；取得运行地偏移边界并对运行共模保证计算。掉电资料不能关闭 RUN 缺口。 |
| WG-02 | 同一接口另有 OFF 状态：对端仍上电，实际注入路径存在，允许注入电流/掉电容忍未知。 | 保留 OFF 注入缺口及条件性后果，按适用保证及实际路径分级；不能因 WG-01 修正状态文案而删掉 OFF。运行态共模证明不能关闭它。 |
| WG-03 | 普通旁路：原厂只推荐名义 0.1 µF，实装名义 0.1 µF、直接供电/地配对正确；审查者建议 Ceff≥70 nF；采购耐压未定。 | 名义旁路窄判据据实 PASS；自设 70 nF 不作为原厂电气阻断；DEV-D04/真实采购额定任务继续开放，未经受控不能称采购完成。 |
| WG-04 | 稳压器输出：原厂保证稳定条件 Ceff≥1 µF；选用 1 µF MLCC，仅有名义值，无工作偏压/温度下有效容量。 | 真实稳定性条款保留 INSUFFICIENT；不能使用 WG-03 的名义旁路结论豁免；补适用有效容量或选器件并按同工况复算。 |
| WG-05 | 两个无源器件产生四行额定资格检查；都缺同一已允许采购系列/耐压的受控记录；其余已核连接与名义值未变。 | 逐行保留会改变判据的采购缺口并归并共同任务；不是四个已确认电气根因。分级须有具体误选后果，不从普通采购字段未知生造热损坏。受控供应商规格可关闭明确保证范围。 |
| WG-06 | 一条 INS 的五个 impact 字段齐全，等级 P1；文字仅“影响该功能，未证明全工况，需补资料”。validator valid=true。 | 字段完整不能证明 P1；追实际供电/信号/保护路径与受控必需功能、独立排除依据。尚未完成追踪标审查未完成；不为完整记录接受模板，也不删除真实资料缺口。 |
| WG-07 | 同一器件隔离两域供电/地各有直接电容；自动候选按芯片 ref 池化返回脚。19 个未检出功能包被逐个 features=NOT_APPLICABLE 声明。 | 用官方脚义与原生供电/返回网络声明 intent.decoupling.groups（v2），不改网络或保证。未检出也未声明包用 REQ-Q08 一行逐个盘点；真实声明/名称候选按 REQ-Q07 保留并复核，不能一刀切 NA。 |

WG-01/02 与 WG-03/04 为相反工况/用途对照；WG-05/06/07 分别检查根因计数、格式与因果、分组与覆盖边界。
已有 `test_review_quality.py`、`test_insufficient_impact.py` 证明疑点筛查与对账不形成电气结论；它们不能自动证明上述人工因果正确。
新方法在真实项目的有效性须由重新独立取证的主审和复核记录验证。

# 忠实提取验收与电气资格：成对专家评价

这是执行方法评价，依据 inputs-and-coverage 与 evidence-proportionality 的既有范围规则。
不新增 catalog 检查，不由模板或自动扫描生成工程结论。

合成输入：一页 ADC/MCU 模块，连接与参考图一致；主机未指定，板上有上拉，
ADC 的本体模拟供电窗口尚未有足够证据。任务 A 只要求忠实提取，明确沿用正常
预编程控制器/官方库作使用前提，排除固件复现和制造采购交付。任务 B 另要求该板
与指定主机、固件版本及总线速率的完整运行保证；目前这些实现/兼容证明未取得。

专家分别建结果及补证/移交动作，逐条解释所属验收主张与实际路径：

| 子判据 | A 的预期处理 | B 的预期处理 |
|---|---|---|
| 已证实连接/字段与参考一致 | 独立保真结论；不因运行资料未知改判提取错误 | 同样保留；不能替代运行判断 |
| 未指定主机的完整双端阈值、总线电容 | 完成本体上拉/能力计算，按明确范围记录端点集成条件；不自行索取一个主机型号 | 指定端点和速率属于承诺，核保证值；缺关键实现证据仍 INSUFFICIENT |
| 固件实现或采购回执未交付 | 记录任务给出的使用条件及后续复现/制造边界，不追加固件复现任务 | 仅对会改变已要求运行/制造结论的缺口建立具体任务 |
| ADC 本体供电窗口未闭合 | 仍 INSUFFICIENT；不以提取范围或工作前提掩盖 | 同样 INSUFFICIENT |
| 候选明确接错 ADC 物理脚 | 仍 FAIL/提取错误，不能借正常使用前提关闭 | 同样 FAIL |

不合格回答：A 与 B 套同一完整系统补证清单；把 A 全部未知一律改 NA；
把未证明的模拟供电改 PASS；用保真一致证明完整运行；或把原图共有问题计为提取引入错误。
评价保留原台账和修订版逐项理由，计数变化只是范围裁定结果，不是电气能力改善的证明。

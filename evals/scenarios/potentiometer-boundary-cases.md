# 双联电位器：物理功能、输出滤波和证据边界

来源：SolderedElectronics/Slider-potentiometer-breakout-hardware-design，commit `a67c092ad512ea55d2c5071bc4e2fcd184d4ee99`，333130/V1.1.1，硬件TAPR OHL1.0、版本引脚图CC BY-SA4。原件、84项初审和独立审核、可复现比较见手动20轮round-02归档。这是人工成对工程判例；不冒称新自动算法、厂家规格或实板测量。

1. **双联结构**：一个R1封装含A/B两条电阻轨道，六个功能端子`1a/2a/3a`、`1b/2b/3b`，滑块机械联动、供电可独立、共地。对照：不能把六脚当二脚固定电阻或把内部轨道相互短接；独立电源不是电气隔离，也不是两个独立滑块位置。
2. **同版参数**：V1.1.1引脚图标明线性10kΩ，SCH/BOM通用SLIDER_POT没有控制名义阻值；可据版本证据提出文档名义值修正。对照：图中10k不证明采购公差、功率、厂家引脚或实际装板型号，不把名义修正当完整资格闭环。
3. **电容用途**：C1/C2=100n在滑臂输出对地，是真实电容和输出滤波，保留电容类型但不强造IC供电去耦分组。对照：零IC不意味着可以漏掉电容耐压；100n/0603也不等于6.3V额定。实际芯片电源脚仍须按本身手册完整去耦。
4. **位置与采样**：理想无负载`Vout=xVcc`，`Rth=R*x*(1−x)`；10k/100n的中点Rth=2.5k、τ=250µs。对照：端点理想Rth趋零，滤波不是固定636.6Hz全行程保证；没有实际ADC/采样/允许误差，不能签整链性能，也不制造本体必须补外部ADC任务。
5. **反灌与开路**：外部强驱动滑臂或对端带电可通过部分轨道反灌掉电VCC；接近端点，限流不能使用全部10k。滑臂开路时100n可能保持历史电位，无默认归零保证。对照：若系统有掉电隔离或失效安全目标，需给真实保护/控制路径与保证条件，不能把普通被动人机输入升级成已有安全承诺。
6. **辅助物理脚**：原PCB除六信号pad还有两个未归网`1b0/1b1` through-hole pad；厂家/装配角色未给。对照：其几何位置像安装部件不构成正式NC或可接地证据，必须记录差集与局部资格缺口；钻孔/环宽或机械实现问题交PCB/结构审核，不能签布局准出。
7. **原生检查与SKU**：原生导出、原PDF和PCB导电成员一致，ERC库查找/电源flag/网格提示分类保留，不宣称cleanERC。对照：实际断网仍是缺陷；共享网页中333131的ATTINY/I2C/UPDI/Qwiic内容不能用于333130原件，不因页面模板制造MCU/固件审查任务。

本例独立复核校正：算出5V/10k名义预算不满足实际器件能力/电压范围裕量的完整PWR-C01，待实际Rmin/源端上界/额定值而保留局部待核；共用W-SPEC动作不支持各ID复制同一缺口和严重度。开放模块输出幅度/共地/掉电注入/位置相关采样及无默认安全态以结构化required:false集成HANDOFF交使用者，不制造未指定主机的额外阻断任务。

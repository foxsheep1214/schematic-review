# 数字 I²S 麦克风：身份、帧与工况边界

人工边界案例，非已自动执行的测试。来源线索：[Adafruit ICS-43434 源电路](https://github.com/adafruit/Adafruit-I2S-MEMS-Microphone-Breakout-PCB/tree/cde79ddef57c7df69a5e7268b66567fa50b7e42d)、[DS-000069 v1.2](https://product.tdk.com/system/files/dam/doc/product/sw_piezo/mic/mems-mic/data_sheet/ds-000069-ics-43434-v1.2.pdf)、[Arduino SAMD Core 1.8.13](https://github.com/arduino/ArduinoCore-samd/tree/5ae2f68c0e1caeede4246c5c0052eb17d2b69698)。只在有独立原证据的审查中使用；此页不授予接口或生产验收。

解决 G2–G4、G7 中把名称/示例/典型值当实际保证的错误，复用 DEV-D01/D02/D04、SIG-T04/C07/C08/C09/D15、RST-T04、PWR-C09 与 DOC-V02；不增加全局固定阻值或等待时间。

| 成对输入 | 应有判断与最小证据 |
|---|---|
| VALUE 是受控数字麦克风，库仍用另一型号名，但全部六个实际编号/功能一致；反例只有 SD/VDD 两脚真的互换 | 前者不能仅库名判实际错料；核真实 identity、物理脚双向差集，PCB land 实现另审。后者连接 FAIL，不能靠相似外形或库兼容撤销。实际型号尚不清的第三分支保留具体身份缺口。 |
| 手册要求 SD 放电，实际 47kΩ，正文明确允许比 100kΩ 更小；反例没有任何放电路径而需求规定空闲确定值 | 前者先算下拉负载/并联及数据定义，不能按参考图常数判错；后者按真实空闲要求和全部驱动/内部路径判断。24 位有效数据结束后高阻，不自动要求全部填充位立即清零。 |
| SD 本地47k下拉在IC侧、68在IC至头之间；反例把同47k移到接收头侧 | 按实际归网而非平面相邻位置复算：前者单板高阻接收没有该47k电流经过68，后者有。双板另一个47k经过两个68形成远端支路；不能把所有并联电流都推过一颗串阻。未给接收漏电/动态负载时不造精确全角压降保证。 |
| 24 位有效数据放在两路 32 位 slot；反例配置两路 24 位 slot却要求每帧64个SCK | 前者有效数据宽与容器宽不同，64 帧可以满足。后者实际48帧不满足受控64条件；查真实寄存器编码、1位延迟和选声道，不能按参数名直接判。未取得底层设置时不伪称已算。 |
| 固定软件请求16kHz，48MHz整数分频得到16.304kHz且落适用低功耗窗口；反例沿用统一2–4MHz指导的4MHz而64SCK对应62.5kHz | 用实际源版本、分频与帧数计算。前者源码可支持条件配置结论，不是实测波形/主机电平保证。后者若真为选定系统设置，越过器件51.6kHz保证；未指定主机的泛指南只作条件风险/文档范围，不捏造本板固定时钟。 |
| 滤波器通带/拐点随fs缩放，48k时约20k/24k；反例明确承诺16k时通带仍到24k | 前者保留采样条件，16k约6.67k/8k不是硬件连接坏掉。后者修正确有误导的明确性能表达；仅说抑制24k以上不等于承诺更低采样率也通到24k，不直接造FAIL。近似软目标与硬验收指标须区别，不从典型频响图补造全温保证。 |
| 供电一般范围1.65–3.63V，但数字时序表条件更窄；反例文档写1.6V也在保证范围 | 表条件分别保留，数字表不能扩展到一般供电两端。反例文档越界可判文档缺陷，不证明某个实际3V实物损坏。未指定外部源不能自造实际1.6V运行，更不能因无指定主机判任意整链PASS。 |
| 禁用麦克风 SD 有高阻条款；反例在VDD=0继续向BCLK/WS输入高电平 | SD 高阻不消除第二模块真实板上的放电电阻/寄生负载，也不授予所有输入 Ioff；按真实掉电绝限、ESD路径和厂家禁供时钟条款查。只缺未指定系统顺序时给具体集成约束；已指定且违反保证则 FAIL，不移交PCB代替。 |
| 一个表写20ms唤醒，另一适用正文写32768时钟且低速算出更长；反例项目真要求固定较短启动时间却只凭营销instant证明 | 保留版本/模式/“开始输出”与“稳定灵敏度”区分以及原文冲突，条件计算和首有效帧验证，不默改厂家保证。无受控零延迟指标的营销instant只作说明建议；麦克风无需额外寄存器配置不等于主机无需PHILIPS/slot配置。典型/代表计算不是已验证整改等待值。 |
| PDF文本提取出现叠入脚表的内部偏置句而像素无该句；反例直接引用提取文本作为该脚保证 | 对照关键页像素、全文实际段落/单位；正文另处真实说明可独立引用。像素缺字不证明器件无偏置，文本多字也不是物理脚表的可靠定位。 |

价值是避免错误替换、虚构接口通过和无意义补证。必须保留真实本体最小物料规格、时序/负载/掉电约束与去耦/声孔实施移交。纯数字单端 I²S 不自动承担 AV 模板里的差分阻抗或强制模拟/数字分地。源码/格式验证不签 PCB、SI/PI、EMC、声学性能或制造。

文档增量的同冻结自动效果可为零，必须按真实回放记录；人工案例条数、提交数和审核一致率不是电气改善成绩。

厂家“strongly recommended”按推荐定型处理，不能改写成原件强制X7R违规或无出处的全角有效C≥100nF。已有数字filter计算必须绑定实际工作条件/需求，不以运放GBW或ADC采样保持规则给它假PASS。

# ADC 跳线与官方示例边界

人工证据判例，工具不自动审查 C++。来源：Soldered 官方 ADS1015 硬件
`cff050bd112222aebd79cc4b2cce2bd37d3164dc` V1.1.1；官方库
`5d2a009e2636a821c7a09527544d976f6091baa3` 1.0.0 / ADS1X15 0.3.1；
TI ADS1015 SBAS473F、ADS1115 SBAS444E。原件/冻结全台账及复现在公开电路校准第13轮归档。

| 正向证据 | 反向或边界证据 | 应作判断 |
|---|---|---|
| R3/R2 各10k供侧经JP1独立闭合铜桥到VCC | JP1断开、DNP、状态未核 | 逐状态发现真实供侧路径；后者不能认有上拉；公共VCC不连接SDA/SCL |
| 无源供侧0Ω有受控装配 | 供侧另有有限33Ω或有源开关 | 0Ω可追轨；有限路径保留阻值/边界，不能将最末电阻当总等效 |
| JP2默认CONNECTED装配要求接GND选48 | JP2实际仅paste，替代地址同时闭合 | 不假称默认有铜桥；改变地址先断原桥再选唯一桥，不将未实施错误选件当原板短路 |
| SCH/BOM ADS1115 与 ADS1015共10脚DGS映射 | README声称ADS1015/12bit/3300SPS | 共脚可证连接，不能消除型号冲突或把16bit860SPS当12bit3300SPS保证 |
| 单次正常完整寄存器返回真实零 | 短读/NACK返回零、isBusy无内部超时 | 真实零与失败必须有独立状态；模拟总线复现不能冒充Arduino实板验证 |
| 已选择芯片/DR且新转换完成 | continuous固定8ms/1ms或刚改MUX | 绑定最慢转换时间与旧样本处理；函数耗时不等于采样吞吐量 |
| signed原始码按2的幂比例换算 | 分母32767/2047 | 记录小幅算术偏差；错误类的码值位移和LSB可能抵消，不未经计算声称×16错误 |
| 真硬件MUX的正端减负端 | 辅助0_2/1_2写成read2减read0/1 | 核API方向与静态符号；顺序单端软件差不能当同步硬件差分，默认示例未调用也不消除该分支问题 |
| RDY的Hi bit15=1、Lo bit15=0、队列启用 | 示例Hi0200、Lo0000 | 后者仍比较器；OS轮询可用不证明RDY脚配置正确，单次/连续模式另核 |
| ADC digital允许到5.5V，AIN正常0..VDD | 3.3pullup声称任意5Vhost，或VDD3.3时AIN5V | 数字耐压不等于host门限；Microchip7810D TWI VIH=.7VCC有合法反例。FSR±6.144不是AIN过压许可 |
| 单颗本体C1名义100n、普通10k负荷很小 | 厂家effective≥.1uF、实际Ceff未受控 | 给局部Ceff/ESR/V/T方案；不强求全部普通件唯一MPN，也不能把名义容量当有效最小值 |

结论必须带具体模式/原件版本/后果。比较器、RDY被调用分支的功能失效按P1，但不重复判成默认轮询硬件失效。
3.3V供电加5V电位器的已指示接法超过AIN3.6V绝限且无板限流，具体损坏风险支持P0；
另一个VDD5V合规分支不因此判P0。普通R/header低应力计算不替代实际额定，只补该用途最小V/P/I/T。
未指定外源带宽/精度时，差分滤波按厂家应用文字给条件和接收者；不能省略其要求，也不能编造
全系统绝对精度指标。未规定故障包络不能自动要求TVS或编P0，但实际掉电AIN钳位路径仍须写清。

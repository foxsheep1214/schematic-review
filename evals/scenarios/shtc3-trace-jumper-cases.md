# SHTC3 X01：铜桥、版本和开放模块边界

来源：sparkfunX/Qwiic_Humidity_SHTC3@60c6841a58d3d78739ceafa6dbd0d0edc0f491ea，CC BY-SA4。案例仅保留判别边界，不是电气golden board或整板通过基准。

| 易误判 | 正确处置 | 反例仍应保留 |
|---|---|---|
| JUMPER-SMT_3_2-NC_TRACE 里的NC判不装配 | NC是normallyclosedtrace；核实际封装两铜桥并独立声明装配/状态 | 独立/NC、DNP/DNI/DNF或原生dnp仍为不装配 |
| 三脚JP只能两脚化/删一脚才能清gap | 显式物理links 1-2/2-3、出处与装配状态，全部脚保留；供电轨不合并SDA/SCL | 未取证模型/未核装配/独立切桥变体不能自动PASS |
| 四脚手册没有作者pad5所以错脚 | 厂家未编号中心EP内部VSS，作者5为本地别名，4/5都映射完整 | 真多余/丢失物理脚或DNU仍须查 |
| v1只列120ns因而100k也只能120ns | 核v1.1及v4模式/版本；100k1000ns但CBmax400pF，公式531pF需取交集400pF | 实际1MHz仍120ns且63.738pF本地预算，不用慢速限值豁免 |
| U1自己的VOL小于自己的VIL等于完整host双端PASS | 全链未定host在本体范围NA；另窄实例核端点能力/实际负载，给INT；不复制RUN到OFF/CUT | 主机一旦指定，全部端点/温度/驱动保证必须复核 |
| 未选电源/未提供所有普通MPN就是本体P1 | 导出真实局部负载包络，保留未知LED连续额定，制造资格/实际环境按任务范围分开 | 本体关键保证或指定系统能力的真实缺口不能删除 |
| 后续红板guide的PWRLED jumper用于本X01 | 实际版本本LED硬连，sleep0.6uA只是传感器不是板总流，没板低功耗目标不造FAIL | 若真实整板亚微安需求明确，LED额外电流必须纳入 |
| 典型±2RH/±.2C与示例RH1..99当全温实测证明 | 正常工况/最大曲线/污染热接触/原始测试日志逐一界定，PCB/装配约束保留 | 真实指定精度或已有测试失败仍须查 |

此例代码增量只改NC_TRACE分类与显式多pad模型，不改变外端C01/C07门禁、电气保证值或普通DNP语义。初审与终审人工范围修正另计，不拿测试数量/提交数/一致率当改善。

# 模块审查范围：成对判例

来源：公开模块审查中把名义功能、未知外设和制造绑定混成待核清单。用于验证
[evidence-proportionality.md](../../references/evidence-proportionality.md) 与
[报告模板](../../references/report-and-remediation.md) 的适用判断；不是自动电气计算测试，也不被单元测试执行。
每次回放根据给定输入产出判定、必要计算/约束和最小补证，不能只检查措辞。

|案例输入|应产生的行为|相邻反例（不得被范围裁定掩盖）|
|---|---|---|
|开放双向开漏转换模块，需求/作者说明限定为通用模块本体，低侧3.3V/2.2k、高侧5V/2.2k，无指定对端|算耦合低电平灌电流；VOL0.4V时约3.409mA。给上拉/电容/门限/未上电端口约束，不因未知主机普遍阻断本体；不能宣称整链PASS。|明确要求兼容只能保证3mA@VOL0.4V的端点时，要继续算MOS压降与实际保证窗口；不能仍以“开放模块”排除兼容性检查。需求未写明审查范围时，范围本身列需求澄清，不由审查者自行判整链NA。|

复验记录应注明这些是场景行为回放；工具结构检查、单元测试数量和未实际运行的模型评测不能替代回放结果。

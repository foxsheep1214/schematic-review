# 称重桥 ADC 的人工成对判例

来源：[Soldered HX711 原版](https://github.com/SolderedElectronics/Load-cell-ampfilier-HX711-board-hardware-design/tree/3440ad0996cce887954f5af0fb2dc2d8b4fc5d51)，V1.1.1，TAPR OHL 1.0。固定同版 CAD/PDF/BOM；仓库另有 V1.2.0 输出，不能冒充同版原件。19 器件、52 个物理脚记录（51 连线、XO13 未连），16 个导出分组（15 真实网与 XO 独点）。限值来自 [AVIA 原始 HX711 文档镜像](https://cdn.sparkfun.com/datasheets/Sensors/ForceFlex/hx711_english.pdf) p2–5（文档未印修订），不是镜像发布日期保证；本例无版本绑定实板或计量认证。

每对右栏均为明确的本地合成条件，不是作者原板故障或已经实施的修改。用于人工判读既有 G1–G7 判据，不提供型号豁免，也不替代原件逐项审查。

| 判据与原件可判范围 | 合成分支及应得结论 |
|---|---|
| RST-T03/T04：PD_SCK 正常读数高时间 0.2–50 µs；高持续 >60 µs 进入掉电，拉低复位后默认 A128。没有指定主机时保留这些集成约束，不能宣称任意 GPIO 默认态安全。 | 明确要求持续正常读数，主机保证每个高脉冲 70 µs：FAIL 时序/模式条件；“低于 60 µs”也不能替代 50 µs 读数上限。30 µs 高满足这一条，仍须核低时间、数据建立、脉冲数；不能整链 PASS。 |
| ANA-C03/REQ-D01：表3规定 25/26/27 脉冲分别 A128/B32/A64；图2末行文字 B64 与表3及通道定义冲突。按明确条款核通道，不把图中文字当器件保证。 | 合成主机以 27 脉冲要求 B64：FAIL 通道/增益配置；改为 A64 只关闭这个配置错误，不证明重量标定或时序合格。 |
| ANA-C03/PWR-C02：R3=20k、R4=8.2k，按 VBG 典型 1.25V 得 AVDD 标称 4.29878V；实际参考无 min/max，不能把该数作为全角保证。AVDD供板上U1.3，2.6–5.5V推荐范围仍构成隐含窗口；无作者精度指标不能把PWR-E01判NA。 | 合成明确要求从 3.3V 输入保证 AVDD=4.30V 的线性 PNP 调节：FAIL 能量/压差要求，非“仅差实测”；若未声明 3.3V 稳压要求，不给作者原件添这一故障。 |
| ANA-C03/DEV-C03：E+ 在 AVDD 后串 10Ω；桥端激励与 ADC 参考不是同一点。350Ω总桥电阻只是示例，E+/AVDD=350/360，标称灵敏度相对直接激励减小 2.7778%，可通过对应标定处理。 | 合成声明“不标定且激励/参考比例必须≥0.99”，实际桥明确350Ω：FAIL 0.97222<0.99；未定义精度指标或实际桥阻时，不把比例变化直接判称重功能失败。 |
| PWR-T03/D02/C09、PWR-C04：AVDD 无直接电容；100n+10µF 在 10Ω 后。直接归网清单须保留零电容，工程判定另核反馈与 RC 稳定条件；不能自动宣称缺电容必失稳，也不能偷偷跨串阻计作直连。 | 合成把 R5 当零欧而照旧称与原件同拓扑：输入/版本核验不通过；若保持10Ω但缺真实稳定条件，具体局部 INSUFFICIENT，不能靠标称电容总量改 PASS。 |
| DEV-D01/D04/D05：XO13 库属性为 input，而表1为晶体 Digital I/O；XI14 接地选择内部振荡器时 XO13 明确允许 NC。库属性与物理未用脚处置分开，错误库属性保留，浮空输入故障排除。 | 合成将 XI14 真正断开且无外部时钟：缺内部时钟选择保证必须重新判定；不能借 XO 的合法 NC 扩大到 XI 的输入。只修 XO 类型不改变任何物理归网，也不关闭其他输入问题。 |
| CLK/ANA、G4：内部振荡器 10 SPS、RATE=0 的 400ms 稳定时间和 50nVrms 输入噪声均为典型值；24位输出码不等于24位保证精度。 | 合成要求全温稳定时间≤400ms或24位有效精度，仅持这些典型值：INSUFFICIENT 保证证据；没有该指标的裸模块，不把新造计量需求登记为作者缺陷。 |
| G7/PWR：原厂p4另允许不用内部模拟稳压器，p6给直接AVDD旁路。原件资格不足时，可给保留原件的条件方案与数值预验算，未知唯一参数并不等于没有可改路径。 | 条件方案将受控外部电源接VSUP/AVDD/DVDD，VFB接地、BASE未连；或把C2从E+移到AVDD。仅原厂模式、名义RC和电压条件可复算，外源 AVDD 不随 PD_SCK 关闭桥激励，低功耗需受控源 enable/开关；实际电源、Ceff/ESR/负载及重新标定未闭合：仍INSUFFICIENT，不以PROPOSED改成原件PASS，也不凭补证困难整批填NONE。 |

保留价值：具体区分读数/掉电模式、条款/图中文字、参考/桥端激励及直连清单/模拟环路，防止时序漏检、错误比例保证和盲目加电容。仅增加人工判例；算法、工程身份及原件自动扫描不变，不能宣称自动误报率或漏检率已提高。按冻结原件重放，真实资格缺口和硬件边界须继续保留。

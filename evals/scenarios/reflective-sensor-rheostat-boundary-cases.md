# 反射传感器与变阻器边界判例

这些是脱敏合成判例，核查实际功能、物理端子和条件，不将型号常数推广为通用门槛。
适用当前 DEV-D02、DEV-C01/C05、REQ-D02、SIG-C08、ANA-T01；不新增规则。

| 对照 | 应当区分的两种情况 | 期望处置 |
|---|---|---|
| 1 非标准位号关键件 | 已用 `intent.devices` 提交完整脚表的光学探头/三端变阻器；仅有普通未声明电阻 | 前者无论位号前缀均展开 DEV-D02，并比较官方与符号两侧差集；后者不能仅按前缀批量升级为关键件。完整端子表中允许未接的端子仍须核查，不能从网中缺失而消失。 |
| 2 变阻器端子 | 滑端与一个电阻膜端连续串联限流，另一个端未用；未使用的实际输入功能脚有明确偏置要求 | 前者按真实变阻器接法判断，不强制未用端绑滑端；后者按其器件条款处置。可选防接触断开方案不冒充强制电气缺陷。 |
| 3 局部膜与滑端功率 | 可变电阻仅使用部分膜且电流经滑端，总功率小于整膜额定；同电流已在允许温度下满足局部膜/滑端条件 | 不能凭总功率放行前者。先核原厂局部膜降额/滑端限值；资料给可用替代方法时按适用条件算。上界超限或典型值超限不直接证明实际过流；具保证边界违反才 FAIL，否则保留具体资格缺口/可计算改法。后者有据通过。 |
| 4 电流文档与真实应力 | 假设5V源、100Ω固定串联限流且无升压，文字声称100mA；实际保证电流越过所用发射器限制 | 前者先以非负压降给名义电流上限50mA，判说明与参数口径不符，不能拿错误文字作为真实100mA应力。后者按实际电气边界判 FAIL。典型Vf算例必须标条件，不变成全温最小/最大保证。 |
| 5 光学条件与接收负载 | 反射光电流/饱和电压仅在指定发射电流、目标反射率、距离、VCE、IC和温度保证；本设计另加指示灯和接收端上拉 | 条款不能转成所有目标/距离或更大灌电流下固定低电平保证。先追负载线/电流/返回路径，明示实际阈值与光学验收；只有名义模拟功能且无硬输出窗口时，不虚构 ADC/运放/TTL 条款。 |
| 6 铜桥区域与装配 | 两功能端之间的非端子铜区同时重叠两边，默认导通且允许切除；第三个真正独立功能端遗漏符号 | 前者列入完整物理区域与切除状态，不伪造第三个NC输入或DNP器件；后者必须列官方/符号差集。切灯支路不意味着仍存在的信号上拉和发射支路也消失。 |
| 7 掉电与器件种类 | 同供电域输入高阻使用的反射传感器；外部常供电源驱动信号且模块断电、信号经上拉回灌 | 前者保留实际共供电/接收边界；后者追实际掉电路径并限定顺序/隔离及适用反压，不编造Ioff保证。反射发射/接收结构不自动等于有电气隔离保证的光耦，不强加CTR或隔离认证。 |

参数只演示判别方法，实际计算以选定器件保证条件、需求和温度降额为准。
局部膜/滑端方法可参见 [Bourns 变阻器应用说明](https://www.bourns.com/docs/technical-documents/technical-library/trimmers/application-notes/bourns_wiper_setting_apno.pdf) pp4–5；
“10%–90%”是其稳定性建议，不能对所有电位器与全部项目设为独立的通用强制FAIL。
新增自动展开只修显式器件 DEV-D02 的覆盖，其余七对照仍需人工取证；未声称经验文字提升了自动电气检测率。

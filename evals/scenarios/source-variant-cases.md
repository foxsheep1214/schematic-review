# 当前源、变体与供电模式：成对判例

来源：OLIMEX BB-CH340T Rev.B，commit `5a938742d46b68978651677682e20d56c27dc8c4`，
公开源符号与历史导出不一致的实证；正向使用证据只覆盖产品族基本串口。
以下为通用合成情景，不把某型号、参考值或作者声誉写成规则豁免。
对齐 G2/G3/G4/G7，复用 DEV-D01/D02/D05、DOC-Q01、PWR-T01、CLK-C01、SIG-C07。

回放记录需保留实际判定、计算与最小补证，不能只匹配这张表的文字。
`scripts/tests/test_source_variant_calibration.py` 仅自动验证当前源遗漏脚、NC对象、陈旧绑定拒绝、
正确相邻变体和空导出拒绝；这些发现/完整性测试不是六个实物电气PASS，也不执行上表的人工审查。

功能物理脚可按原厂A/K等名称核对，不虚构统一数字焊盘；实装VF/电容等影响电气保证的缺口仍需保留，制造焊盘绑定移交。原厂去耦要求不可因名义选值筛查而消失；明确名义/实际有效值的判据边界，必要时先反算最小保留比例，而非一律索取所有普通件全温曲线。

# 精密并联基准：位号、偏置、精度与物理脚

来源：Adafruit-LM4040-Voltage-Reference-PCB，commit `6e1c7a03f744e43faf24efe80b1913821f83badb`，原图CC BY-SA3.0；TI LM4040-N SNOS633H（作者链接）与SNOS633N（2025-08），A/I、DBZ适用脚表和电气表。正式原件、全台账及冻结对照位于公开电路校准手动20轮round-01归档。以下为人工成对判例，不冒称实板测试或全部自动检测实现。

1. **位号覆盖**：`D1/D2` 是显式 `intent.devices` 中具有完整身份和脚表的关键分流基准，不因非U/M位号遗漏DEV-D01/C05/D05。对照：未声明的普通D器件不能仅凭位号推断其集成基准身份；资料缺失仍WAITING_EVIDENCE，声明本身不产生PASS。连接器使用独立条款，未用脚检查不重复。
2. **额定功率**：12V、2.048V、750Ω的偏置电阻名义耗散0.132W；0805尺寸不证明额定0.125W或0.25W，实际最小规格缺证保留局部INSUFFICIENT。对照：若有受控适用温度0.125W额定，复算应力超过额定才可确认FAIL；受控0.25W仍须考虑温度降额和公差，不自动GO。
3. **负载与分流**：偏置电流必须分为外部负载、板上10kΩ泄放与基准电流；全温最低D1 65µA、D2 73µA，最大工作15mA。对照：忽略10kΩ或将20mA绝对最大值当工作上限会降低保证，禁止。不能把15mA误写成两输出任意可用的负载电流。
4. **精度条件**：A等级0.1%是25℃、100µA初始条件，实际电流/温度/自热误差另算；保守保证误差上限不证明每个实物必然超差。对照：有明确全输入/全温整板目标时，必须完整误差预算或局部待核，不能用初始等级放行。
5. **NC与电容**：DBZ pin3为die attach，手册允许浮空或接pin2；原图浮空合法，稳定性不要求输出电容。对照：真正DNU或明确要求最小有效容量的另一器件仍按本身手册判，不能把本例允许关系泛化到任意NC/电源脚。
6. **非正常工作域**：作者3V模式仅允许2.048V支路，4.096V支路未稳压不是违反该模式需求。掉电外部带电输出可能通过750Ω反灌VIN，须明确使用限制；对照：若要求掉电隔离，另核完整路径与保证值，不能从合法3V例外推导Ioff或安全启动保证。

# USB-C Breakout v10：物理脚、角色与工作额定边界

来源：sparkfun/USB-C-Breakout@c37b0849e0db8a6f9a3df06f9301f303fe85cd8f，作者v10/CC BY-SA4。对照2026 USB-IF TypeC2.5适用章节与该版本作者原图/官方链接BSC资料。此例保留人工审查判别边界，不是自动电气golden board，不新增全局常数或保证值。

| 易误判 | 本例正确处置 | 反例与关闭条件 |
|---|---|---|
| symbol/netlist28地址就是所有物理脚 | 枚举package发现A8/B8 SBU存在未映射；纳入30地址、查BRD未配网；USB2/noAltmode按4.3允许开路 | 需要SBU的USB4/Altmode、错误开路/DNU或真正多余脚须重审；导入完整不等于厂家pinout正确 |
| 16接触点/铜区/跨层地址一一相等 | 四VBUS/GND成对合并铜区；四壳腿共8层别名，保留来源映射且不虚构8实际壳腿 | 丢失真正脚/错误alias、层上不同位置/导电关系不得因名字近似合并 |
| NO_POP端子被当作整件电气消失 | J3无贴装header但6个裸铜焊盘用于接线，仍为实际导电边界，查全针序 | 真不装配电阻/IC及明确不连铜器件仍依实际装配；不能自动泛化所有NO_POP为装配 |
| 有两5.1k Rd就默认申请1.5/3A | Rd建立Sink连接；超默认取电需实际CC监测/广告变化跟踪及真实电流路径资格，本例无负载控制器 | 指定整体1.5/3A负载后缺监测/不能跟踪是实际电气问题，不能以开放模块范围逃避 |
| D+两副引脚并网为短路，必须USB2MUX | USB2.5 4.5.1.1要求同极性D+副本并网、D−副本并网，翻转可用 | D+与D−相互短路、CC1/CC2并网、USB3/USB4TX/RX混接仍错误 |
| 壳地只算后续EMC移交 | 本金属USB2数据插座SHLD孤岛，现行3.2.1note11要求PCBground；确认本体缺连接并给接法（当前SR强制接口不符合P1），后布局bond验收另移交 | PowerOnly类型有适用例外，须核实际模式/触点；不能对所有接口/绝缘壳强加固定接地/RC拓扑；后文informative should实现指南不撤销前文适用SHALL连接条件 |
| AC100V一分钟/系列5A证明默认5.5V工作/板5A | 介电试验非连续工作额定；系列写5.0V不能自动证明5.5V上界。保留实际工作电压最小资格缺口，系列5A不传成板承载 | 原厂明确名义5V覆盖defaultmax或已批准连续额定可关闭；无证据只待核，不直接宣布已损坏 |
| 2015/2022概要阈值/20V-100W是现行全部规范 | 原始版本与现行2.5适用条件逐一核；CC修订示例±10%disconnect<=.276V不是通用比较器定值 | 实际选定探测器要按源方法/公差/地偏移/泄漏模型算；历史证据不替当前模式保证，未提供实测日志不算实测 |

本轮不修改执行引擎：同冻结输入与判据两侧原生结果一致，自动误报/漏检/多余待核变化均为0；上述经验服务后续人工复核。已知壳地缺陷与连接器工作额定待核仍保留；不通过项各有接法或具体最小数据、取得路径与复验关闭条件。未选PHY的REXT/端接/整链阈值、未声明系统ESD/整板电流不额外制造P1任务。

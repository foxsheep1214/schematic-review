# Passive tactile-input boundary cases

Eight synthetic human review pairs. Evaluate each stated claim separately; these are not automated detector tests. Numerical illustration is not an unprovided source, resistor tolerance, temperature or procurement guarantee. Use the current catalog and evidence-proportionality rules.

| Pair | Supported case | Contrasting case | Expected distinction |
|---|---|---|---|
| Five active-low paths | Five independent outputs have individual pullups to an external rail and momentary contacts to a common return. | One pullup is omitted with no other bias, or that contact is wired to the wrong output. | The local topology claim passes in the first case; a demonstrable departure from the declared five-channel function fails in the second. Do not assume an unspecified host repairs it. |
| Contact maximum versus minimum | The applicable contact document states a maximum voltage/current and contact resistance, with no minimum wetting condition. | The selected, different contact document explicitly requires a minimum operating current and the actual pullup current is below it. | Never invent a minimum from a maximum or import it across models. An explicit applicable lower-bound violation remains a failure; actual-unit failure is a separate claim. |
| Six terminals and two tabs | Manufacturer geometry and circuit distinguish six numbered electrical terminals from two unnumbered cover-retention lands. | An extra unmapped pad has no evidence establishing whether it is functional, exposed power or mechanical. | An explicit alias table can prove the first six-terminal mapping; neither library `NC` spelling nor lack of a net proves the second pad harmless. Mechanical tabs are not DNP or official electrical NC terminals. |
| Pullup versus pressed-contact fault | Source current reaches a closed contact through its individual pullup. | An external push-pull output reaches that closed contact directly, bypassing the pullup. | Compute the first source current through R; do not use that R to claim the second fault is limited. Track each actual path and its return. |
| Nominal function and local ratings | A generic nominal resistor and actual contact topology support a limited qualitative function claim. | A rating or bounded application claim requires actual minimum resistance, power and voltage capability which is not established. | Qualitative topology evidence does not close the second local stress check. Keep only the minimum material/source specification needed; one common specification task can cover several distinct checks, without demanding every ordinary full MPN. |
| Open host and specified host | An open module exports signals; no host thresholds, power sequencing or numeric event rate are declared. | A particular host and timing/voltage envelope are explicitly required. | Preserve module leakage/low-level/backfeed formulas and input-mode/debounce constraints in the first case; perform the real two-end comparison in the second. Missing host data must not hide the module's own unknown ratings. |
| Physical view and numerical reading | A numbered manufacturer top view is matched through an explicit pad alias and board rotation; the small resistance unit is rechecked on an enlarged original page. | BOM-item numbers or a mirrored view are used as electrical terminals, or an ambiguous low-resolution digit is adopted without checking. | Use actual electrical labels/view and original-page units; preserve mistaken observations and corrections. Pixel appearance alone is not evidence of a different document revision. |
| Iteration report and freeze gate | A design-iteration report separates complete review, open local specification tasks and unclaimed guarantees; machine release metadata is contextual. | A machine `release=NO_GO` value is copied as the iteration's overall decision, or `valid=true` is treated as electrical approval. | Reconciliation validity and freeze eligibility are distinct from the current engineering conclusion. A later freeze request still needs its actual applicable guarantees and release checks. |

The archived real review supplies provenance and disagreements privately. This file adds decision distinctions, not a fixed resistor tolerance, universal voltage range, debounce duration, required protection topology or contact-current floor. Claim no automatic improvement from these human pairs alone.

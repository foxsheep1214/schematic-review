## 二、致命（BLOCKER）

### E-01　负载开关 U3 的 EN 脚超绝对最大额定，上电即损坏

- **位置**：02 页 U3（LS-24A 负载开关）pin 4，网络 `SW_EN_24V`
- **证据链**：
  - 网表：`R21 (100K/1%，实装) → VIN_24V`；`SW_EN_24V` 网上无其他分压器件 → EN 脚被直接拉至 **24V**
  - datasheet `LS-24A` p.4 Absolute Maximum Ratings：`EN … −0.3V to +5.5V`
- **影响**：上电瞬间 EN 脚承受 24V，超绝对最大额定 4.4 倍，**器件立即损坏**，且可能连带上游 24V 源
- **根因**：EN 为低有效（`Active-low enable`，datasheet Table 2），设计者按"上拉即关断"的直觉直接拉到输入轨，未查 EN 耐压
- **改法**：`VIN_24V —R21(100K)— SW_EN_24V —R22(22K,新增)— GND` 分压至 4.3V，或改用 3.3V 域上拉
- **验证**：改后复算 `24 × 22/(100+22) = 4.33V < 5.5V` ✓
- **置信度：A（网表实证）+ B（datasheet 已核）**

### E-02　稳压管 D7 直接跨接在超过其 Vz 的电源轨上

- **位置**：03 页 D7（ZD-3V0，Vz=3.0V），两端 = `VCC_5V0` / `GND`
- **证据链**：网表 D7 阴极在 `VCC_5V0`（L3 实算 5.06V），阳极在 `GND`；datasheet `ZD-3V0` p.2 `Vz = 3.0V ±5% @ 5mA`，`Pd = 200mW`
- **影响**：5.06V 持续加在 3.0V 稳压管上 → 反向击穿区持续导通，功耗 ≈ (5.06−3.0)²/R_dyn 远超 200mW，**上电即烧毁并短路 5V 轨**
- **根因**：BOM 选型笔误，同封装 SOD-523 的 ZD-3V0 与 ZD-5V6 极易混料
- **改法**：D7 换 ZD-5V6（Vz 5.6V > 5.06V）或整体删除（该轨已有 TVS D5 保护）
- **验证**：改后 `Vz(min) = 5.6×0.95 = 5.32V > 5.06V` ✓
- **置信度：A + B**

## 三、严重（Warning）

### W-01　PHY-G 的 `TEST_MODE` 脚上拉，违反 datasheet 强制条款

- **位置**：05 页 U7 pin 33，网络 `PHY_TEST`
- **证据**：datasheet `PHY-G` p.17 引脚表原文：`TEST_MODE  33  IPD  Reserved. **Must be pulled down.**`；网表 `R58 (4.7K，实装) → VCC_3V3`，下拉位 `R59 (4.7K/NC)` 未贴
- **影响**：PHY 上电进入测试模式，正常链路不建立
- **改法**：R58 → /NC，R59 → 实装。**纯 BOM 改动**
- **置信度：A + B**

### W-02　欠压监控动作点与图纸注释不符（串联下臂被漏算）

- **位置**：02 页 U9（SUP-062 电压监控，阈值 0.62V）VIN1 分压
- **证据**：网表上臂 `R31 = 68K`；**下臂为 R32(2.2K) + R33(4.7K) 串联 = 6.9K**，非图纸注释所指的单颗 2.2K
- **实算**：`VTH = 0.62 × (68+6.9)/6.9 = **6.73 V**`；图纸注释标 `V1=20V`
- **若误按下臂 2.2K 计算**：`0.62 × 70.2/2.2 = 19.78V` ≈ 注释值 —— 说明注释是按错误模型写的
- **影响**：24V 轨欠压保护点实际在 6.73V（28%），远低于设计意图，形同虚设
- **规范依据**：图框自印规范「电源命名需标明实际电压或做好电压注释」
- **改法**（需设计者裁决，**C 级**）：若确需 20V 动作点，下臂改 2.18K（68/(20/0.62−1)）；若 6.73V 可接受，改注释
- **置信度：A + B**

### W-03　ESD 器件挂在残网，被保护信号实际裸奔

- **位置**：06 页 D12（ESD 阵列）pin 2，网络 `USB_DP_OLD`
- **证据**：`USB_DP_OLD` 仅 1 个节点（只有 D12.2）；真实 USB 信号走 `USB_DP`（3 节点：U1.88、J5.3、C40.1），两网互不相通
- **根因**：改版时 USB 走线改名，ESD 器件未随之迁移（旧网名残留）
- **改法**：D12.2 改接 `USB_DP`，`USB_DP_OLD` 删除
- **置信度：A**

## 六、误报排除（X-xx）——已定性归档

### X-01　`NC` 网络 88 节点不是短路

L0 规则命中一张名为 `NC` 的 88 节点网络，覆盖多个 IC 的保留脚。**两路独立证据判定为工具伪网络**：
1. 全库 267 张网络的实例行均带层次路径 `@<设计名>(SCH_1):<网名>`，**唯独 `NC` 是裸字面量**；
2. 网表导出日志中「No_connect 属性被忽略并强行连线」的 5 条告警，其引脚一律落在**真实网络**，无一落入 `NC`。

→ 不构成缺陷。后续轮次遇同一命中可直接引用本条。

### X-02　12 条单节点网全部合法

全部为 SoC 引出到连接器但本板未使用的外设信号（MIPI/PCIe/SDIO），属 L0-01 白名单明列的「被删外设引脚」。**真实死网络 = 0。**

## 七、PCB Layout 必须携带的约束

1. **大电流**：24V 输入 → U3 负载开关 → U4 buck（峰值 3A），载流与压降按峰值核算
2. **差分/等长**：RGMII（串阻靠近驱动端）、网变到 RJ45 的 TRX0~3±、USB
3. **隔离**：隔离 CAN 域的爬电/电气间隙按认证要求，隔离栅下方禁止铺铜跨越
4. **去耦就近**：SoC-A 各电源域、PHY-G 的 AVDD/DVDD
5. **热**：U4（24V→5V）压差大、损耗集中，需散热铜箔
6. **测试点**：全板 46 个 TP 需保证可触探
